# U37. 한자 읽기의 원리

### 오늘의 목표

- 음독과 훈독이 어떻게 생겼는지 설명할 수 있다
- 한국 한자음으로 일본 음독을 추측하는 규칙을 쓸 수 있다
- 연탁·촉음화·반탁음화로 읽기가 바뀌는 원리를 안다
- 숙자훈(今日·大人처럼 단어 전체로 읽는 말)을 60개 이상 읽을 수 있다
- 일본 신자체와 한국 정자, 일본에서 만든 국자를 구별한다

### 음독과 훈독

| | 음독(音読み) | 훈독(訓読み) |
|---|---|---|
| 정체 | 중국 한자음을 일본식으로 받아들인 소리 | 한자의 뜻에 맞는 일본 고유어를 붙인 읽기 |
| 표기(사전) | 가타카나: 山 サン | 히라가나: 山 やま |
| 주로 쓰는 곳 | 두 글자 이상 한자어: 登山(とざん), 火山(かざん) | 한 글자 단어, 오쿠리가나가 붙는 동사·형용사: 山(やま), 生きる(いきる) |
| 한국어와의 관계 | 한국 한자음과 뿌리가 같아 비슷함 | 한국어에는 없는 체계(한국어 '뫼 산'의 '뫼'에 해당) |

- 한 한자에 음독이 여러 개인 이유: 중국에서 들여온 **시대가 달라서**입니다. 오음(呉音, 가장 오래됨) → 한음(漢音, 표준) → 당송음(唐音, 드묾). 行: 呉音 ギョウ(行事), 漢音 コウ(旅行), 唐音 アン(行脚).
- 한 한자에 훈독이 여러 개인 이유: 한자 하나의 뜻을 여러 일본어 단어에 썼기 때문입니다. 生: いきる(살다)·うまれる(태어나다)·はえる(나다)·なま(날것)… → **읽기가 다르면 뜻도 다릅니다.** 한자 단원(U38–U48)의 표가 읽기별로 예시를 나눈 이유입니다.

### 한국 한자음 → 일본 음독 대응 규칙

한국어 화자의 가장 큰 무기입니다. 받침과 초성의 대응을 알면 처음 보는 한자어도 읽기를 꽤 맞힐 수 있습니다.

**받침(끝소리) 대응** — 가장 규칙적

| 한국 받침 | 일본 음독 끝 | 예 (한국음 → 일본음) |
|---|---|---|
| ㅇ | う / い (장음) | 상 → しょう(商)·そう(相), 경 → けい(経)·きょう(京), 동 → どう(動)·とう(東), 공 → こう(工) |
| ㄱ | く / き | 학 → がく(学), 국 → こく(国), 석 → せき(石), 역 → えき(駅), 육 → いく(育) |
| ㄹ | つ / ち | 일 → いち·にち(一·日), 발 → はつ(発), 결 → けつ(決), 실 → しつ(室), 설 → せつ(説) |
| ㅂ | う (옛 표기 ふ) | 합 → ごう(合), 법 → ほう(法), 급 → きゅう(急), 입 → にゅう(入), 십 → じゅう(十) |
| ㄴ, ㅁ | ん | 산 → さん(山), 삼 → さん(三), 문 → もん·ぶん(門·文), 남 → なん(南), 감 → かん(感) |
| 없음 | 모음으로 끝 | 가 → か(家), 지 → ち(地), 부 → ふ(父), 고 → こ(古) |

**초성(첫소리) 대응** — 경향

| 한국 초성 | 일본 | 예 |
|---|---|---|
| ㄱ·ㅋ | か행·が행 | 가 → か(家), 기 → き·ぎ(気·技), 공 → こう(工) |
| ㅎ | か행 (!) | 학 → がく, 한 → かん(漢), 화 → か(火)·わ(話), 회 → かい(会) |
| ㅂ·ㅍ | は행·ば행 | 발 → はつ, 부 → ふ, 병 → びょう·へい(病·兵), 편 → へん·べん |
| ㅁ | ま행·ば행 | 문 → もん·ぶん, 미 → み·び(未·美), 만 → まん·ばん |
| ㄴ | な행 | 남 → なん, 년 → ねん(年), 내 → ない(内) |
| ㅇ(이·인·일) | じ·に | 인 → じん·にん(人), 일 → にち·じつ(日), 이 → じ·に(二·耳) |
| ㅅ·ㅈ·ㅊ | さ행·ざ행 | 산 → さん, 정 → せい(正), 차 → しゃ(車), 주 → しゅ·じゅう(主·住) |
| ㄷ·ㅌ | た행·だ행 | 대 → だい·たい(大), 도 → と·ど(図·度), 통 → つう(通) |
| ㄹ | ら행 | 리 → り(理), 로 → ろ(路), 력 → りょく(力) |

[교육용 설명] 규칙이 100%는 아니지만, 한자어의 대부분에서 받침 규칙은 거의 맞습니다. 経済(경제 → けい·ざい), 準備(준비 → じゅん·び), 関係(관계 → かん·けい), 発達(발달 → はっ·たつ), 合格(합격 → ごう·かく). 어휘 표의 `한자음` 열과 대조하며 익히세요.

**ㅎ → か행이 가장 낯선 규칙입니다**: 漢(한 → かん), 会(회 → かい), 海(해 → かい), 行(행 → こう), 学(학 → がく), 号(호 → ごう), 化(화 → か), 歓(환 → かん).

### 연탁·촉음화·반탁음화 — 붙으면 소리가 바뀐다

| 현상 | 규칙 | 예 |
|---|---|---|
| 연탁(連濁) | 뒤 단어의 첫 청음이 탁음으로 | 人+人 → ひとびと, 本+棚 → ほんだな, 手+紙 → てがみ, 三+階 → さんがい |
| 촉음화 | 앞 글자 끝 く·き·つ·ち가 っ으로 | 学+校 → がっこう, 一+回 → いっかい, 出+発 → しゅっぱつ, 結+果 → けっか |
| 반탁음화 | ん·っ 뒤의 は행이 ぱ행으로 | 散+歩 → さんぽ, 一+分 → いっぷん, 発+表 → はっぴょう, 出+版 → しゅっぱん |
| 연성(連声) | ん 뒤 모음이 な행으로 | 反+応 → はんのう, 天+皇 → てんのう |

### 신자체와 정자 — 일본과 한국의 모양 차이

일본은 1946년 이후 한자 모양을 간략하게 바꾼 **신자체**를 씁니다. 한국은 **정자(번체)**를 그대로 씁니다 [S18]. 한자 단원의 제목 괄호 안이 한국 정자입니다.

| 気 | 氣 | 来 | 來 | 体 | 體 |

### 한자 공부 순서 추천

1. **한국 훈음으로 뜻 잡기** — 生 '날 생' → '나다, 살다'
2. **대표 음독 하나** — 한국음 '생'에서 せい 추측(받침 ㅇ → い)
3. **자주 쓰는 훈독 단어** — 生きる, 生まれる
4. **단어로 외우기** — 한자 한 글자의 읽기를 외우기보다 先生·一生·生きる처럼 단어째로
5. **급수 순서대로, 빈도 순서대로** — U38(N5)부터, 각 단원 안은 자주 쓰는 순서
