# U03. N5 문법 ① 명사문과 조사

### 오늘의 목표

- 「AはBです」로 자기소개와 사물 소개를 할 수 있다
- こ·そ·あ·ど 지시어를 거리에 맞게 쓸 수 있다
- 기본 조사 は·が·を·に·へ·で·と·も·の·から·まで의 뜻을 말할 수 있다
- は와 が의 차이를 예문으로 설명할 수 있다
- 숫자·시간·날짜를 읽을 수 있다

### 명사문 — です·ではありません·でした

#### AはBです / AはBではありません
- **뜻** A는 B입니다 / A는 B가 아닙니다
- **접속** 명사 + です / ではありません(회화: じゃありません·じゃないです)

| 예문 | 해석 |
|---|---|
| 私は キムです。韓国人です。 | 저는 김입니다. 한국인입니다. |
| 田中さんは 先生ではありません。 | 다나카 씨는 선생님이 아닙니다. |
| これは 私の 傘じゃないです。 | 이것은 제 우산이 아닙니다. |

#### ～でした / ～ではありませんでした (과거)

| 예문 | 해석 |
|---|---|
| 昨日は 休みでした。 | 어제는 휴일이었습니다. |
| 前の 仕事は 銀行員ではありませんでした。 | 전 직업은 은행원이 아니었습니다. |

#### ～ですか (의문) · はい／いいえ
문장 끝에 か를 붙이면 의문문입니다. 일본어는 물음표 대신 마침표(。)를 쓰는 것이 원칙입니다.

| 예문 | 해석 |
|---|---|
| 山田さんは 会社員ですか。— はい、そうです。 | 야마다 씨는 회사원입니까? — 네, 그렇습니다. |
| これは 日本の お茶ですか。— いいえ、中国の お茶です。 | 이것은 일본 차입니까? — 아니요, 중국 차입니다. |

#### ～も (~도) · ～の (~의)
- も는 は·が·を 자리를 대신합니다(は+も가 아님).
- の는 소유·소속·내용·출신을 나타냅니다. 한국어는 '의'를 자주 생략하지만 일본어는 명사와 명사 사이에 거의 반드시 の를 넣습니다.

| 예문 | 해석 |
|---|---|
| 私も 学生です。 | 저도 학생입니다. |
| サムスンの 社員 / 日本語の 本 / ソウルの 出身 | 삼성 사원 / 일본어 책 / 서울 출신 |
| これは だれの かばんですか。— 私のです。 | 이것은 누구 가방입니까? — 제 것입니다. |

[교육용 설명] '私の(제 것)'처럼 の 뒤의 명사를 생략하면 '~의 것'이 됩니다.

### 지시어 こ·そ·あ·ど

| | 말하는 사람 쪽 こ | 듣는 사람 쪽 そ | 둘 다 먼 쪽 あ | 의문 ど |
|---|---|---|---|---|
| 사물 | これ 이것 | それ 그것 | あれ 저것 | どれ 어느 것 |
| 명사 수식 | この 이 | その 그 | あの 저 | どの 어느 |
| 장소 | ここ 여기 | そこ 거기 | あそこ 저기 | どこ 어디 |
| 방향·정중 | こちら 이쪽 | そちら 그쪽 | あちら 저쪽 | どちら 어느 쪽 |
| 종류 | こんな 이런 | そんな 그런 | あんな 저런 | どんな 어떤 |

- これ·それ는 혼자 쓰고, この·その는 반드시 뒤에 명사가 옵니다: この本(○), この(×).
- こちら·そちら는 장소·사람의 정중한 표현입니다: こちらは 田中さんです(이분은 다나카 씨입니다), お手洗いは どちらですか(화장실은 어디입니까).
- **한국어와 다른 점**: 대화에서 앞에 나온 화제를 가리킬 때, 상대가 말한 것은 そ, 둘 다 아는 옛일은 あ를 씁니다. 「あの店、また 行きたいね」(그 가게 또 가고 싶다 — 둘 다 아는 가게).

### 조사 ① は·が·を·に·へ·で

| 조사 | 기본 뜻 | 예문 | 해석 |
|---|---|---|---|
| は (와) | 주제 '~은/는' | 私は 学生です。 | 저는 학생입니다. |
| が | 주어 '~이/가', 대상 | 雨が 降っています。 | 비가 오고 있습니다. |
| を | 목적어 '~을/를' | パンを 食べます。 | 빵을 먹습니다. |
| を | 지나가는 곳·떠나는 곳 | 公園を 散歩します。/ 家を 出ます。 | 공원을 산책합니다. / 집을 나섭니다. |
| に | 시간 '~에' | 7時に 起きます。 | 7시에 일어납니다. |
| に | 존재 장소 '~에' | 部屋に 猫が います。 | 방에 고양이가 있습니다. |
| に | 도착점·대상 '~에(게)' | 学校に 行きます。/ 友達に 電話します。 | 학교에 갑니다. / 친구에게 전화합니다. |
| へ (에) | 방향 '~(으)로' | 東京へ 行きます。 | 도쿄로 갑니다. |
| で | 동작의 장소 '~에서' | 図書館で 勉強します。 | 도서관에서 공부합니다. |
| で | 수단·도구 '~(으)로' | バスで 来ました。/ 箸で 食べます。 | 버스로 왔습니다. / 젓가락으로 먹습니다. |

**한국어 화자가 자주 틀리는 곳**

- **'~을/를 만나다·타다'는 に**: 友達に 会います(친구를 만납니다), 電車に 乗ります(전철을 탑니다).
- **'~이/가 좋다·싫다·능숙하다·알다·필요하다'는 が**: 犬が 好きです(개를 좋아합니다), 日本語が 分かります(일본어를 압니다).
- **장소 + に vs で**: 존재(いる·ある·住む)는 に, 동작은 で. 東京に 住んでいます / 東京で 働いています.
- 시간에 に를 붙이지 않는 말: 今日·明日·毎日·今週·去年 등 상대적인 시간 → 明日 行きます(明日に ×).

### 조사 ② と·や·から·まで·より·か·ね·よ

| 조사 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| と | ~와/과(전부 나열), ~와 함께 | パンと 牛乳を 買いました。/ 友達と 行きます。 | 빵과 우유를 샀습니다. / 친구와 갑니다. |
| や | ~랑, ~이나(일부 나열) | 机の 上に 本や ノートが あります。 | 책상 위에 책이랑 노트(등)가 있습니다. |
| から | ~부터, ~에서 | 9時から 5時まで 働きます。 | 9시부터 5시까지 일합니다. |
| まで | ~까지 | 駅まで 歩きます。 | 역까지 걷습니다. |
| より | ~보다 | 今日は 昨日より 寒いです。 | 오늘은 어제보다 춥습니다. |
| か | ~나, ~인지 | コーヒーか 紅茶を 飲みます。 | 커피나 홍차를 마십니다. |
| ね | 동의 구하기 '~네요, ~지요' | いい 天気ですね。 | 날씨가 좋네요. |
| よ | 알려 주기 '~요(어조 강조)' | この 店、安いですよ。 | 이 가게 싸요(알려 줌). |

[교육용 설명] ね는 상대도 알거나 공감할 내용에, よ는 상대가 모르는 정보를 알려 줄 때 씁니다. 모르는 사람에게 よ를 많이 쓰면 가르치려는 듯 들릴 수 있습니다.

### は와 が — 한국어 '은/는·이/가'와 같은 점, 다른 점

대부분은 한국어 감각과 같습니다(は = 은/는, が = 이/가). 헷갈리는 장면만 정리합니다.

| 장면 | 쓰는 조사 | 예문 | 해석 |
|---|---|---|---|
| 의문사(だれ·何·どこ)가 주어일 때 | が | だれが 来ましたか。— 田中さんが 来ました。 | 누가 왔습니까? — 다나카 씨가 왔습니다. |
| 처음 등장하는 정보 / 눈앞의 일 묘사 | が | あ、雨が 降っている。 | 아, 비가 온다. |
| 이미 아는 화제를 꺼낼 때 | は | 田中さんは どこですか。 | 다나카 씨는 어디 있어요? |
| 대비(다른 것과 비교) | は | 肉は 食べますが、魚は 食べません。 | 고기는 먹지만 생선은 안 먹습니다. |
| 명사 수식절·종속절 안의 주어 | が | 私が 作った ケーキです。 | 제가 만든 케이크입니다. |
| 好き·嫌い·上手·下手·分かる·できる·ほしい의 대상 | が | 私は 音楽が 好きです。 | 저는 음악을 좋아합니다. |

- 「私は 学生です」(나는 학생이다 — 나에 대한 설명) vs 「私が 学生です」(학생인 사람은 바로 나다 — 누가 학생인지에 대한 답).
- 부정문은 は가 자연스럽습니다: お金は ありません(돈은 없습니다 — 다른 건 몰라도).

### 숫자·시간·날짜 읽기

**숫자**: いち·に·さん·よん(し)·ご·ろく·なな(しち)·はち·きゅう(く)·じゅう / 百 ひゃく · 千 せん · 万 まん

- 소리가 바뀌는 수: 300 さんびゃく · 600 ろっぴゃく · 800 はっぴゃく · 3000 さんぜん · 8000 はっせん
- 1만 = いちまん(만 앞에 いち를 붙임), 1억 = いちおく

**시간**: 何時(なんじ) — 4시 よじ · 7시 しちじ · 9시 くじ / 분: 1분 いっぷん · 2분 にふん · 3분 さんぷん · 4분 よんぷん · 5분 ごふん · 6분 ろっぷん · 7분 ななふん · 8분 はっぷん · 10분 じゅっぷん · 30분 さんじゅっぷん(半 はん)

**요일**: 月曜日 げつようび · 火 か · 水 すい · 木 もく · 金 きん · 土 ど · 日 にちようび

**날짜(외워야 하는 특수 읽기)**: 1일 ついたち · 2일 ふつか · 3일 みっか · 4일 よっか · 5일 いつか · 6일 むいか · 7일 なのか · 8일 ようか · 9일 ここのか · 10일 とおか · 14일 じゅうよっか · 20일 はつか · 24일 にじゅうよっか (나머지는 숫자+にち: 11일 じゅういちにち)

**월**: 4월 しがつ · 7월 しちがつ · 9월 くがつ (よんがつ·なながつ·きゅうがつ는 틀림)

[교육용 설명] 조수사(〜個·〜本·〜枚·〜人 등) 전체 표는 '한눈에 복습 → 숫자와 조수사'에 있습니다.

# U04. N5 문법 ② 형용사·동사·존재

### 오늘의 목표

- い형용사·な형용사로 사물과 사람을 설명할 수 있다
- 동사 ます형의 네 가지 꼴(ます·ません·ました·ませんでした)을 쓸 수 있다
- あります와 います를 구별해 위치를 말할 수 있다
- 희망·권유·비교 표현으로 간단한 대화를 할 수 있다

### 형용사 문장

| | い형용사 (高い) | な형용사 (静か) |
|---|---|---|
| 현재 | 高いです | 静かです |
| 현재 부정 | 高くないです / 高くありません | 静かじゃないです / 静かではありません |
| 과거 | 高かったです | 静かでした |
| 과거 부정 | 高くなかったです | 静かじゃなかったです |
| 명사 수식 | 高い かばん | 静かな 部屋 |

| 예문 | 해석 |
|---|---|
| この ラーメンは とても おいしいです。 | 이 라멘은 아주 맛있습니다. |
| 昨日の 試験は 難しくなかったです。 | 어제 시험은 어렵지 않았습니다. |
| 駅の 近くは にぎやかでした。 | 역 근처는 번화했습니다. |
| ここは 静かで きれいな 公園です。 | 여기는 조용하고 깨끗한 공원입니다. |
| 新しくて 安い パソコンが ほしいです。 | 새롭고 싼 컴퓨터를 갖고 싶습니다. |

**주의**: 「おいしいでした」(×) → おいしかったです(○). い형용사 과거는 형용사 자체를 바꿉니다.

#### どう·どんな — 감상 묻기

| 예문 | 해석 |
|---|---|
| 日本の 生活は どうですか。— 楽しいですが、ちょっと 忙しいです。 | 일본 생활은 어때요? — 즐겁지만 좀 바쁩니다. |
| 田中さんは どんな 人ですか。— 優しい 人ですよ。 | 다나카 씨는 어떤 사람이에요? — 상냥한 사람이에요. |

### 동사 ます형

| | 긍정 | 부정 |
|---|---|---|
| 현재·미래 | 行きます (갑니다·가겠습니다) | 行きません (안 갑니다) |
| 과거 | 行きました (갔습니다) | 行きませんでした (안 갔습니다) |

| 예문 | 해석 |
|---|---|
| 毎朝 6時に 起きます。 | 매일 아침 6시에 일어납니다. |
| 週末は どこへも 行きませんでした。 | 주말에는 아무 데도 가지 않았습니다. |
| 明日 友達と 映画を 見ます。 | 내일 친구와 영화를 봅니다. |
| 何を 飲みますか。— 水を お願いします。 | 무엇을 마시겠습니까? — 물 부탁합니다. |

#### 의문사 + も (전부 부정)
何も·だれも·どこへも + 부정 = 아무것도·아무도·아무 데도 ~않다.

| 예문 | 해석 |
|---|---|
| 朝から 何も 食べていません。 | 아침부터 아무것도 안 먹었습니다. |
| 教室に だれも いません。 | 교실에 아무도 없습니다. |

### 존재 — あります·います

| | 쓰는 대상 | 예문 | 해석 |
|---|---|---|---|
| あります (ある) | 사물·식물·장소·사건 | 机の 上に 本が あります。 | 책상 위에 책이 있습니다. |
| います (いる) | 사람·동물(움직이는 것) | 公園に 子供が います。 | 공원에 아이가 있습니다. |

- 「장소に 물건が あります」 (~에 ~이 있다) / 「물건は 장소に あります」 (~은 ~에 있다)
- 위치 명사: 上 うえ · 下 した · 前 まえ · 後ろ うしろ · 中 なか · 外 そと · 隣 となり · 近く ちかく · 間 あいだ · 右 みぎ · 左 ひだり
- 가족·일정 소유에도 씁니다: 兄が 二人 います(형이 둘 있습니다), 明日 テストが あります(내일 시험이 있습니다).

| 예문 | 해석 |
|---|---|
| 銀行は 郵便局の 隣に あります。 | 은행은 우체국 옆에 있습니다. |
| 冷蔵庫の 中に 何が ありますか。 | 냉장고 안에 무엇이 있습니까? |
| 猫は いすの 下に います。 | 고양이는 의자 밑에 있습니다. |

### 희망 — ～たい·～がほしい

#### 동사 ます형(ます 뗌) + たい — ~하고 싶다
い형용사처럼 활용합니다(たくない·たかった). 대상 조사는 を 또는 が.

| 예문 | 해석 |
|---|---|
| 日本へ 行きたいです。 | 일본에 가고 싶습니다. |
| 今日は 何も 食べたくないです。 | 오늘은 아무것도 먹고 싶지 않습니다. |
| 子供の とき、医者に なりたかったです。 | 어렸을 때 의사가 되고 싶었습니다. |

#### 명사 + がほしい — ~을 갖고 싶다

| 예문 | 해석 |
|---|---|
| 新しい スマホが ほしいです。 | 새 스마트폰을 갖고 싶습니다. |
| 今は 何も ほしくないです。 | 지금은 아무것도 갖고 싶지 않습니다. |

[교육용 설명] ～たい·ほしい는 **나(또는 질문할 때 상대)의 희망**에만 씁니다. 제3자는 「行きたがっています」(가고 싶어 합니다)처럼 ～がる를 씁니다(U07). 손윗사람에게 「先生、コーヒーが ほしいですか」는 실례 — 「コーヒーは いかがですか」(커피 어떠세요)라고 권합니다.

### 권유 — ～ませんか·～ましょう·～ましょうか

| 표현 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| ～ませんか | ~하지 않을래요?(정중한 권유) | 一緒に 昼ご飯を 食べませんか。 | 같이 점심 먹지 않을래요? |
| ～ましょう | ~합시다 | ええ、食べましょう。 | 네, 먹읍시다. |
| ～ましょうか | ~할까요?(제안·도움) | 荷物を 持ちましょうか。 | 짐을 들어 드릴까요? |

### 비교와 최상급

| 형태 | 예문 | 해석 |
|---|---|---|
| AはBより ～ | 東京は ソウルより 大きいです。 | 도쿄는 서울보다 큽니다. |
| AとBと どちらが ～か | 犬と 猫と どちらが 好きですか。 | 개와 고양이 중 어느 쪽을 좋아해요? |
| ～のほうが ～ | 猫の ほうが 好きです。 | 고양이 쪽을 좋아합니다. |
| ～の中で 何/だれ/どこが いちばん ～か | 果物の 中で 何が いちばん 好きですか。 | 과일 중에서 무엇을 제일 좋아해요? |
| ～が いちばん ～ | りんごが いちばん 好きです。 | 사과를 제일 좋아합니다. |

### 확인 문제

**Q1.** 과거형으로: ① 楽しい ② 便利だ ③ いい

<details><summary>정답 보기</summary>

① 楽しかったです ② 便利でした ③ よかったです (いい는 よ로 활용)

</details>

**Q2.** あります/います 중 알맞은 것: ① 駅の 前に タクシーが（　） ② 木の 上に 鳥が（　） ③ 明日 会議が（　）

<details><summary>정답 보기</summary>

① あります(택시는 사물) ② います ③ あります(사건·일정)

</details>

**Q3.** 일본어로: '같이 커피 마시지 않을래요?' / '짐 들어 드릴까요?'

<details><summary>정답 보기</summary>

一緒に コーヒーを 飲みませんか。 / 荷物を 持ちましょうか。

</details>

# U05. N5 문법 ③ て형·ない형·た형과 기본 표현

### 오늘의 목표

- て형으로 부탁·진행·허가·금지·순서를 말할 수 있다
- ない형으로 '~하지 마세요·~해야 한다·~하지 않아도 된다'를 말할 수 있다
- 시간 순서(まえに·あとで·とき·ながら)를 표현할 수 있다
- 「と思います」「と言いました」로 생각과 말을 전할 수 있다
- 정중체 문장을 보통체로 바꿀 수 있다

### て형 ① 부탁·진행·상태

#### ～てください — ~해 주세요

| 예문 | 해석 |
|---|---|
| ここに 名前を 書いてください。 | 여기에 이름을 써 주세요. |
| もう少し ゆっくり 話してください。 | 좀 더 천천히 말해 주세요. |
| ちょっと 待ってください。 | 잠깐 기다려 주세요. |

#### ～ています — ① ~하고 있다(진행) ② ~해 있다(결과 상태) ③ 습관·직업

| 예문 | 해석 | 용법 |
|---|---|---|
| 今 ご飯を 食べています。 | 지금 밥을 먹고 있습니다. | 진행 |
| 窓が 開いています。 | 창문이 열려 있습니다. | 결과 상태 |
| 結婚しています。/ ソウルに 住んでいます。 | 결혼했습니다. / 서울에 삽니다. | 상태 |
| 毎朝 ジョギングを しています。 | 매일 아침 조깅을 합니다. | 습관 |
| 銀行で 働いています。 | 은행에서 일합니다. | 직업 |

**한국어 화자 주의**: '결혼했다·알고 있다·살고 있다'는 일본어로 ～ている입니다. 「結婚しました」는 '결혼식을 올렸다(사건)'에 가깝고, 기혼 상태는 「結婚しています」. '알다'는 「知っています」, 모르면 「知りません」(知っていません ×).

### て형 ② 허가·금지·순서

| 표현 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| ～てもいいです | ~해도 됩니다 | 写真を 撮っても いいですか。 | 사진 찍어도 됩니까? |
| ～てはいけません | ~하면 안 됩니다 | ここで たばこを 吸っては いけません。 | 여기서 담배를 피우면 안 됩니다. |
| ～て、～ | ~하고(순서) | 朝 起きて、顔を 洗って、ご飯を 食べます。 | 아침에 일어나서 세수하고 밥을 먹습니다. |
| ～てから | ~하고 나서 | 宿題を してから 遊びます。 | 숙제를 하고 나서 놉니다. |

[교육용 설명] 허락을 구할 때 대답: 「はい、どうぞ」(네, 하세요) / 「すみません、ちょっと…」(죄송하지만 좀…) — 일본어는 거절을 끝까지 말하지 않고 「ちょっと…」로 흐리는 경우가 많습니다.

### ない형 표현

| 표현 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| ～ないでください | ~하지 마세요 | ここに 車を 止めないでください。 | 여기에 차를 세우지 마세요. |
| ～なければなりません | ~해야 합니다 | 明日は 早く 起きなければなりません。 | 내일은 일찍 일어나야 합니다. |
| ～なくてもいいです | ~하지 않아도 됩니다 | 靴を 脱がなくても いいです。 | 신발을 벗지 않아도 됩니다. |

- 회화에서는 なければなりません을 줄여 「～なきゃ」「～なくちゃ」라고 합니다: もう 行かなきゃ(이제 가야 해).

### 시간 순서 — まえに·あとで·とき·ながら

| 표현 | 접속 | 예문 | 해석 |
|---|---|---|---|
| ～まえに | 동사 사전형 / 명사の | 寝る まえに 歯を 磨きます。/ 食事の まえに | 자기 전에 이를 닦습니다. / 식사 전에 |
| ～たあとで | 동사 た형 / 명사の | 授業が 終わった あとで 図書館へ 行きます。 | 수업이 끝난 후에 도서관에 갑니다. |
| ～とき | 보통체 / 명사の | 暇な とき、何を しますか。/ 子供の とき | 한가할 때 무엇을 합니까? / 어렸을 때 |
| ～ながら | 동사 ます형(ます 뗌) | 音楽を 聞きながら 勉強します。 | 음악을 들으면서 공부합니다. |

- **～とき의 시제**: 「日本へ 行く とき、かばんを 買いました」(일본 가기 전에, 가는 길에 샀다) vs 「日本へ 行った とき、かばんを 買いました」(일본에 가서 샀다). とき 앞 동사의 시제가 '뒤 동작보다 먼저냐 나중이냐'를 나타냅니다.
- ～ながら는 같은 사람이 두 동작을 동시에 할 때. 주된 동작이 뒤에 옵니다.

### 생각·말 전하기 — と思います·と言います

| 표현 | 접속 | 예문 | 해석 |
|---|---|---|---|
| ～と思います | 보통체 | 明日は 雨が 降ると 思います。 | 내일은 비가 올 것 같습니다(라고 생각합니다). |
| | | この 店は 高くないと 思います。 | 이 가게는 비싸지 않다고 생각합니다. |
| | | 田中さんは 学生だと 思います。 | 다나카 씨는 학생일 거예요. (명사·な형용사는 だ) |
| ～と言います | 직접·간접 인용 | 先生は「明日 テストが あります」と 言いました。 | 선생님은 "내일 시험이 있습니다"라고 말했습니다. |
| | | 田中さんは 来週 帰ると 言っていました。 | 다나카 씨는 다음 주에 돌아간다고 했어요. |
| ～でしょう | 보통체(だ 뗌) | 明日は 晴れるでしょう。 | 내일은 맑겠지요. (일기예보·추측) |

[교육용 설명] 일본어는 의견을 말할 때 단정하지 않고 「～と思います」를 자주 붙입니다. 회의·발표에서 「～です」 대신 「～だと思います」로 말하면 부드럽게 들립니다(U65).

### 보통체로 말하기

친한 사이의 대화는 보통체입니다. U02 활용표를 바탕으로 짧은 대화를 바꿔 봅니다.

| 정중체 | 보통체 |
|---|---|
| 明日、何を しますか。 | 明日、何する? |
| 映画を 見に 行きます。 | 映画 見に 行く。 |
| 昨日は 忙しかったですか。 | 昨日 忙しかった? |
| いいえ、忙しくなかったです。 | ううん、忙しくなかった。 |
| これは 田中さんの 傘ですか。 | これ、田中さんの 傘? |
| そうです。 | うん、そう。 |

- 보통체 질문은 か 없이 끝을 올려 말합니다(行く↗).
- 회화에서는 を·は 같은 조사가 자주 빠집니다(映画 見に 行く).
- 동사 ます형 + に 行く = '~하러 가다': 映画を 見に 行きます(영화 보러 갑니다), 買い物に 行きます(쇼핑하러 갑니다 — 명사+に).

### 확인 문제

**Q1.** 알맞은 형태로: ① ここで 写真を（撮る）いいですか ② 薬を（飲む）なりません ③ 明日は 会社に（来る）いいです(오지 않아도)

<details><summary>정답 보기</summary>

① 撮っても ② 飲まなければ ③ 来なくても

</details>

**Q2.** '결혼했습니다(기혼 상태)'와 '모릅니다'를 일본어로.

<details><summary>정답 보기</summary>

</details>

**Q3.** 보통체로: 昨日は 雨でしたか。— いいえ、雨じゃなかったです。

<details><summary>정답 보기</summary>

</details>
