# U59. 기본 생활 회화

### 오늘의 목표

- 인사·자기소개를 상황(처음 만남·이웃·학교)에 맞게 할 수 있다
- 편의점·식당·옷가게에서 주문하고 계산할 수 있다
- 길을 묻고 대중교통(전철·버스·택시)을 이용할 수 있다

### 회화 연습법

[교육용 설명] 대화표의 `해석` 열을 가림펜으로 가리고 일본어만 소리 내어 읽은 뒤, 반대로 일본어 열을 가리고 해석만 보고 일본어로 말해 보세요. 생활 장면 문형은 국제교류기금의 생활 일본어 교재 「いろどり」[S19]의 장면 구성을 참고했습니다(대화는 자체 작성).

### 인사 — 하루의 인사와 헤어질 때

| 장면 | 일본어 | 해석 |
|---|---|---|
| 아침 | おはようございます。/ おはよう。(친구) | 안녕하세요(아침). / 안녕. |
| 낮 | こんにちは。 | 안녕하세요. |
| 저녁 | こんばんは。 | 안녕하세요(저녁). |
| 헤어질 때 | さようなら。/ じゃあ、また。/ またね。(친구) | 안녕히 가세요. / 그럼 또. / 또 봐. |
| 먼저 갈 때 | お先に失礼します。 | 먼저 가 보겠습니다. |
| 잘 때 | おやすみなさい。 | 안녕히 주무세요. |
| 나갈 때 / 배웅 | 行ってきます。/ 行ってらっしゃい。 | 다녀오겠습니다. / 다녀오세요. |
| 돌아왔을 때 / 맞이 | ただいま。/ おかえりなさい。 | 다녀왔습니다. / 어서 와요. |
| 식사 전 / 후 | いただきます。/ ごちそうさまでした。 | 잘 먹겠습니다. / 잘 먹었습니다. |
| 오랜만 | お久しぶりです。お元気でしたか。 | 오랜만이에요. 잘 지내셨어요? |
| 감사 / 대답 | ありがとうございます。/ いいえ、どういたしまして。 | 감사합니다. / 천만에요. |
| 사과 / 대답 | すみません。/ いいえ、大丈夫ですよ。 | 죄송합니다. / 아니에요, 괜찮아요. |

[교육용 설명] 「すみません」은 사과뿐 아니라 '저기요'(부를 때), '고맙습니다'(수고를 끼쳤을 때)로도 씁니다. 가게에서 점원을 부를 때도 「すみません」.

### 자기소개 — 처음 만났을 때

| 화자 | 대사 | 해석 |
|---|---|---|
| 田中 | はじめまして。田中と申します。 | 처음 뵙겠습니다. 다나카라고 합니다. |
| キム | はじめまして。キム・ジウです。韓国から来ました。 | 처음 뵙겠습니다. 김지우입니다. 한국에서 왔습니다. |
| 田中 | キムさんは、お仕事ですか、留学ですか。 | 김 씨는 일 때문에 오셨어요, 유학이세요? |
| キム | 仕事です。IT企業でエンジニアをしています。 | 일이에요. IT 기업에서 엔지니어로 일하고 있어요. |
| 田中 | そうですか。日本は長いんですか。 | 그렇군요. 일본에 오래 계셨어요? |
| キム | いえ、まだ三か月です。日本語もまだまだで……。 | 아뇨, 아직 3개월이에요. 일본어도 아직 서툴러서……. |
| 田中 | いえいえ、とてもお上手ですよ。 | 아니에요, 아주 잘하시는데요. |
| キム | ありがとうございます。これからどうぞよろしくお願いします。 | 감사합니다. 앞으로 잘 부탁드립니다. |

**핵심 표현**
- 「～と申します」(~라고 합니다, 정중) / 「～です」(~입니다)
- 「まだまだです」(아직 멀었어요) — 칭찬받으면 겸손하게 받는 것이 자연스럽습니다.
- 자기소개 뼈대: 이름 → 어디서 왔는지 → 하는 일 → 취미(선택) → よろしくお願いします.

### 편의점에서

| 화자 | 대사 | 해석 |
|---|---|---|
| 店員 | いらっしゃいませ。 | 어서 오세요. |
| 店員 | お弁当、温めますか。 | 도시락 데워 드릴까요? |
| 客 | はい、お願いします。 | 네, 부탁해요. |
| 店員 | 袋はご利用ですか。 | 봉투 필요하세요? |
| 客 | いえ、大丈夫です。 | 아뇨, 괜찮아요. |
| 店員 | お箸はおつけしますか。 | 젓가락 넣어 드릴까요? |
| 客 | 一つお願いします。 | 하나 부탁해요. |
| 店員 | 合計で 680円です。 | 합계 680엔입니다. |
| 客 | カードで払えますか。 | 카드로 계산할 수 있나요? |
| 店員 | はい。こちらにタッチしてください。……ありがとうございました。 | 네. 여기에 터치해 주세요. ……감사합니다. |

**바꿔 말하기**: 「レシートは結構です」(영수증은 괜찮아요) · 「ポイントカードはお持ちですか。— 持っていません」(포인트 카드 있으세요? — 없어요) · 「電子マネーで」(전자 화폐로)

### 식당에서

| 화자 | 대사 | 해석 |
|---|---|---|
| 店員 | いらっしゃいませ。何名様ですか。 | 어서 오세요. 몇 분이세요? |
| 客 | 二人です。 | 두 명이요. |
| 店員 | おたばこは吸われますか。 | 담배 피우세요? |
| 客 | いいえ。 | 아니요. |
| 店員 | こちらへどうぞ。ご注文がお決まりになりましたら、お呼びください。 | 이쪽으로 오세요. 주문이 정해지시면 불러 주세요. |
| 客 | すみません。このランチセットを二つください。 | 저기요. 이 런치 세트 두 개 주세요. |
| 店員 | お飲み物はいかがなさいますか。 | 음료는 어떻게 하시겠어요? |
| 客 | アイスコーヒーを一つと、ウーロン茶を一つ。食後にお願いします。 | 아이스커피 하나랑 우롱차 하나요. 식후에 부탁해요. |
| 客 | (食後) すみません、お会計をお願いします。 | (식후) 저기요, 계산 부탁해요. |
| 店員 | ご一緒でよろしいですか。 | 같이 계산하시겠어요? |
| 客 | 別々でお願いします。 | 따로 부탁해요. |

**핵심 표현**: 「～をください」「～をお願いします」(주문) · 「おすすめは何ですか」(추천 메뉴는 뭐예요?) · 「これ、辛いですか」(이거 매워요?) · 「お水をもらえますか」(물 좀 주시겠어요?) · 「アレルギーがあるんですが、えびは入っていますか」(알레르기가 있는데 새우가 들어 있나요?)

### 길 묻기

| 화자 | 대사 | 해석 |
|---|---|---|
| A | すみません、ちょっとお聞きしてもいいですか。 | 저기요, 잠깐 여쭤봐도 될까요? |
| B | はい、どうぞ。 | 네, 말씀하세요. |
| A | 駅はどうやって行けばいいですか。 | 역은 어떻게 가면 돼요? |
| B | この道をまっすぐ行って、二つ目の信号を右に曲がってください。 | 이 길을 똑바로 가서 두 번째 신호등에서 오른쪽으로 꺾으세요. |
| B | 曲がるとすぐ左側に見えますよ。 | 꺾으면 바로 왼쪽에 보여요. |
| A | 歩いて何分ぐらいですか。 | 걸어서 몇 분 정도예요? |
| B | 五分ぐらいですね。 | 5분 정도예요. |
| A | ありがとうございました。 | 감사합니다. |

**방향 표현**: まっすぐ(똑바로) · 右/左に曲がる(우/좌회전) · ～を渡る(~을 건너다) · ～の角(~의 모퉁이) · 突き当たり(막다른 곳) · ～の向かい(~의 맞은편) · ～の隣(~ 옆) · 交差点(교차로) · 信号(신호등) · 横断歩道(횡단보도)

# U60. 생활 실전 회화

### 오늘의 목표

- 병원에서 증상을 설명하고 약국에서 약을 받을 수 있다
- 관공서(구청)·은행에서 필요한 절차를 진행할 수 있다
- 부동산에서 집을 구하고 조건을 말할 수 있다
- 전화로 예약·문의·재배달 요청을 할 수 있다

### 병원에서

| 화자 | 대사 | 해석 |
|---|---|---|
| 受付 | 今日はどうされましたか。 | 오늘은 어디가 불편하세요? |
| 患者 | 昨日の夜から熱があって、喉がひりひり痛いんです。 | 어젯밤부터 열이 있고 목이 따끔따끔 아파요. |
| 受付 | 初診ですか。保険証をお願いします。この問診票にご記入ください。 | 초진이세요? 보험증 부탁드립니다. 이 문진표를 작성해 주세요. |
| 医師 | 熱は何度ありましたか。 | 열은 몇 도 있었어요? |
| 患者 | 38度5分です。咳も少し出ます。 | 38.5도요. 기침도 조금 나요. |
| 医師 | 薬のアレルギーはありますか。 | 약 알레르기 있으세요? |
| 患者 | 特にありません。 | 특별히 없어요. |
| 医師 | 風邪ですね。三日分のお薬を出しておきます。お大事に。 | 감기네요. 사흘 치 약을 처방해 드릴게요. 몸조리 잘하세요. |

**증상 표현**: 頭がずきずき痛い(머리가 욱신욱신 아프다) · お腹を壊した(배탈이 났다) · 吐き気がする(구역질이 난다) · めまいがする(현기증이 난다) · 鼻水が出る(콧물이 난다) · 寒気がする(오한이 난다) · 足首をひねった(발목을 삐었다) · かゆい(가렵다) · だるい(나른하다)

**약국에서**: 「この薬は一日三回、食後に飲んでください」(이 약은 하루 세 번 식후에 드세요) · 「眠くなることがあるので、運転は控えてください」(졸릴 수 있으니 운전은 삼가세요) · 「お薬手帳はお持ちですか」(약 수첩 있으세요?)

### 구청(区役所)에서

| 화자 | 대사 | 해석 |
|---|---|---|
| 住民 | すみません、転入の手続きをしたいんですが。 | 저기요, 전입 신고를 하고 싶은데요. |
| 職員 | こちらの転入届にご記入ください。在留カードはお持ちですか。 | 이 전입 신고서를 작성해 주세요. 재류 카드 가지고 계세요? |
| 住民 | はい、これです。 | 네, 여기요. |
| 職員 | 国民健康保険の加入もこちらでできますが、会社の保険には入っていますか。 | 국민건강보험 가입도 여기서 할 수 있는데, 회사 보험에 가입되어 있으세요? |
| 住民 | はい、会社の保険に入っています。 | 네, 회사 보험에 가입되어 있어요. |
| 職員 | では、手続きは以上です。住民票の写しが必要なときは、マイナンバーカードがあればコンビニでも取れますよ。 | 그럼 수속은 이상입니다. 주민표 사본이 필요하면 마이넘버 카드가 있으면 편의점에서도 뗄 수 있어요. |

[교육용 설명] 일본에 이사하면 14일 이내에 거주지 구청·시청에 전입 신고(転入届)를 해야 합니다. 외국인은 재류 카드를 가져갑니다. 절차의 세부는 지자체 안내를 확인하세요.

### 은행에서

| 장면 | 일본어 | 해석 |
|---|---|---|
| 계좌 개설 | 口座を開きたいんですが、何が必要ですか。 | 계좌를 만들고 싶은데 뭐가 필요해요? |
| 필요 서류 | 在留カードと印鑑が必要ですか。サインでも大丈夫ですか。 | 재류 카드와 도장이 필요해요? 사인으로도 괜찮아요? |
| 송금 | 韓国に送金したいんですが、手数料はいくらですか。 | 한국에 송금하고 싶은데 수수료가 얼마예요? |
| 카드 분실 | キャッシュカードをなくしてしまったので、止めてもらえますか。 | 현금 카드를 잃어버려서 정지해 주실 수 있어요? |
| ATM | このATMで韓国のカードは使えますか。 | 이 ATM에서 한국 카드 쓸 수 있어요? |

### 집 구하기 (부동산)

| 화자 | 대사 | 해석 |
|---|---|---|
| 客 | 部屋を探しているんですが。 | 방을 찾고 있는데요. |
| 店員 | ご希望の条件はございますか。 | 원하시는 조건 있으세요? |
| 客 | 駅から徒歩10分以内で、家賃は8万円以下がいいです。 | 역에서 걸어서 10분 이내, 월세 8만 엔 이하면 좋겠어요. |
| 店員 | 間取りはいかがですか。 | 방 구조는 어떻게 하실래요? |
| 客 | 1Kか 1DKで、バスとトイレは別がいいです。 | 1K나 1DK로, 욕실과 화장실은 분리된 게 좋아요. |
| 店員 | 敷金・礼金なしの物件もございます。こちらはいかがでしょう。 | 시키킨·레이킨 없는 물건도 있습니다. 이건 어떠세요? |
| 客 | 内見できますか。 | 집 보러 갈 수 있어요? |
| 店員 | はい、今からご案内できますよ。 | 네, 지금부터 안내해 드릴 수 있어요. |

# U61. 친구와의 대화 — 반말·축약형·맞장구

### 오늘의 목표

- 정중체 대화를 친구 사이의 보통체(タメ口)로 바꿀 수 있다
- 회화 축약형(～ちゃう·～てる·～なきゃ·～じゃん)을 알아듣고 쓸 수 있다
- 맞장구(相づち)와 감탄 표현으로 대화를 이어 갈 수 있다
- 감정을 자연스럽게 표현할 수 있다

### 반말로 바꾸는 법

| 정중체 | 친구 사이 |
|---|---|
| 何をしていますか。 | 何してるの? / 何してる? |
| 行きませんか。 | 行かない? |
| 行きましょう。 | 行こう! / 行こうよ。 |
| 分かりません。 | 分かんない。 |
| そうですね。 | そうだね。/ だよね。 |
| 本当ですか。 | ほんと? / マジで?(속어) |
| 大丈夫ですか。 | 大丈夫? |
| ちょっと待ってください。 | ちょっと待って。 |
| ありがとうございます。 | ありがとう。/ サンキュー。 |
| すみません。 | ごめん。/ ごめんね。 |

[교육용 설명] 일본에서 반말(タメ口)은 친한 사이·동갑·손아랫사람에게 씁니다. 처음 만난 동년배라도 처음에는 です·ます를 쓰다가 상대가 「タメ口でいいよ」(반말 해도 돼)라고 하면 바꾸는 것이 무난합니다. 직장 선배에게는 친해져도 정중체가 기본입니다.

### 회화 축약형

| 원래 형태 | 축약 | 예 |
|---|---|---|
| ～ている | ～てる | 何してるの? (何をしているの) |
| ～ておく | ～とく | 予約しとくね。 |
| ～てしまう / でしまう | ～ちゃう / じゃう | 全部食べちゃった。/ 飲んじゃった。 |
| ～なければ(ならない) | ～なきゃ / なくちゃ | もう帰らなきゃ。 |
| ～では / じゃ | ～じゃ | それじゃ、また。 |
| ～ではないか | ～じゃん | いいじゃん! (좋잖아!) |
| ～と言っていた | ～って(言ってた) | 田中さん、来ないって。 |
| ～のだ | ～んだ | 明日、休みなんだ。 |
| ～ら·れ (ら행) | ～ん | 分からない → 分かんない, つまらない → つまんない |
| ～というのは | ～って | 「ググる」って何? |
| そういう / そういうこと | そっか / そういうこと | あ、そっか! (아, 그렇구나!) |

### 맞장구(相づち) — 대화를 이어 주는 말

일본어 대화에서는 상대가 말하는 중간중간 맞장구를 자주 칩니다. 맞장구가 없으면 '안 듣는다'고 느낄 수 있습니다.

| 맞장구 | 뜻·뉘앙스 |
|---|---|
| うん / うんうん | 응, 응응 |
| そうなんだ / そうなんですか | 그렇구나 / 그렇군요 |
| へえ～ | 오~(관심·놀람) |
| なるほど | 아하, 과연(납득) — 손윗사람에겐 「なるほどですね」보다 「そうなんですね」가 무난 |
| たしかに | 확실히, 맞아 |
| それで? / で? | 그래서? |
| わかる～ | 알아, 공감해 |
| うそ! / マジで? | 진짜? 말도 안 돼! |
| すごいね / すごい! | 대단하다! |
| いいね! | 좋다! |
| 大変だったね | 힘들었겠다 |
| それな(속어) | 그러니까, 내 말이 |

### 대화 — 주말 계획

| 화자 | 대사 | 해석 |
|---|---|---|
| ゆい | ねえ、今週末ひま? | 있잖아, 이번 주말 한가해? |

# U62. 의견 나누기 — 동의·반대·부탁·거절·사과·불만

### 오늘의 목표

- 의견을 말하고 이유를 붙일 수 있다
- 상대 의견에 부드럽게 동의·반대할 수 있다
- 부탁하고, 일본식으로 완곡하게 거절할 수 있다
- 상황에 맞게 사과하고, 정중하게 불만을 말할 수 있다

### 의견 말하기

| 표현 | 해석 | 강도 |
|---|---|---|
| ～と思います | ~라고 생각합니다 | 기본 |
| ～んじゃないかと思います | ~이지 않을까 싶어요 | 부드러움 |
| 私としては～ | 저로서는 ~ | 개인 의견 강조 |
| 個人的には～ | 개인적으로는 ~ | 부드러움 |
| ～べきだと思います | ~해야 한다고 생각합니다 | 강함 |
| 理由は二つあります。一つ目は～、二つ目は～ | 이유는 두 가지입니다. 첫째는~, 둘째는~ | 논리적 |
| たとえば～ | 예를 들면 | 예시 |

### 동의와 반대

| 동의 | 해석 | 반대(부드럽게) | 해석 |
|---|---|---|---|
| 私もそう思います。 | 저도 그렇게 생각해요. | おっしゃることは分かりますが…… | 말씀하시는 건 알겠지만…… |
| その通りですね。 | 맞는 말씀이에요. | たしかにそうですが、一方で…… | 분명 그렇지만 한편으로…… |
| 賛成です。 | 찬성입니다. | ちょっと違う意見なんですが…… | 조금 다른 의견인데요…… |
| いい考えですね。 | 좋은 생각이네요. | ～という見方もできるんじゃないでしょうか。 | ~라는 관점도 있지 않을까요? |
| なるほど、勉強になります。 | 그렇군요, 배우게 되네요. | 私は少し反対です。 | 저는 조금 반대예요. |

[교육용 설명] 일본어 토론에서는 바로 「反対です」라고 하기보다 **상대 의견을 먼저 인정하고**(「たしかに」「おっしゃる通り」) 뒤에 「ただ」「でも」로 자기 의견을 붙이는 것이 자연스럽습니다. N1 통합이해 글의 「確かに～。しかし～」 구조와 같습니다(U58).

### 부탁하기

| 정중도 | 표현 | 해석 |
|---|---|---|
| 친구 | ちょっと手伝って。/ 手伝ってくれる? | 좀 도와줘. / 도와줄래? |
| 보통 | 手伝ってもらえますか。 | 도와주실 수 있어요? |
| 정중 | 手伝っていただけませんか。 | 도와주시지 않겠습니까? |
| 매우 정중 | お手数ですが、お手伝いいただけないでしょうか。 | 번거로우시겠지만 도와주실 수 없을까요? |
| 미안함 섞기 | 忙しいところ悪いんだけど、ちょっといい? | 바쁜데 미안한데, 잠깐 괜찮아? |

### 거절하기 — 일본식 완곡 화법

일본어 거절의 기본 구조: **① 감사·사과 → ② 이유(흐리기) → ③ 대안·다음 기회**

| 화자 | 대사 | 해석 |
|---|---|---|
| 先輩 | 今度の金曜、飲みに行かない? | 이번 금요일에 한잔하러 안 갈래? |
| ジウ | 誘ってくださってありがとうございます。 | 불러 주셔서 감사합니다. |
| ジウ | ただ、金曜日はちょっと用事がありまして……。 | 다만 금요일은 좀 볼일이 있어서요……. |
| ジウ | また今度、ぜひ誘ってください。 | 다음에 꼭 불러 주세요. |
| 先輩 | そっか、残念。じゃあ、また今度ね。 | 그렇구나, 아쉽다. 그럼 다음에 하자. |

**거절에 쓰는 말**: 「ちょっと……」(좀……) · 「今回は遠慮しておきます」(이번에는 사양할게요) · 「せっかくなんですが」(모처럼인데요) · 「行きたいのはやまやまなんですが」(가고 싶은 마음은 굴뚝같지만) · 「考えておきます」(생각해 볼게요 — 사실상 거절인 경우가 많음)

### 사과하기

| 상황 | 표현 | 해석 |
|---|---|---|
| 가벼운 실수 | ごめん! / すみません。 | 미안! / 죄송해요. |
| 늦었을 때 | 遅れてすみません。電車が遅れてしまって。 | 늦어서 죄송해요. 전철이 늦어져서요. |
| 정중 | 申し訳ありません。 | 죄송합니다. |
| 매우 정중 | 大変申し訳ございませんでした。 | 대단히 죄송했습니다. |
| 재발 방지 | 今後このようなことがないよう、気をつけます。 | 앞으로 이런 일이 없도록 조심하겠습니다. |
| 사과 받기 | いえいえ、気にしないでください。 | 아니에요, 신경 쓰지 마세요. |

### 정중하게 불만 말하기

| 화자 | 대사 | 해석 |
|---|---|---|
| 住民 | すみません、隣の部屋の者なんですが。 | 실례합니다, 옆집 사람인데요. |
| 住民 | 夜遅くに音楽の音が聞こえてきて、ちょっと眠れなくて……。 | 밤늦게 음악 소리가 들려서 좀 잠을 못 자서요……. |
| 住民 | 申し訳ないんですが、11時以降は少し小さくしていただけると助かります。 | 죄송한데 11시 이후에는 조금 줄여 주시면 감사하겠습니다. |
| 隣人 | あっ、すみません! 気づきませんでした。気をつけます。 | 앗, 죄송합니다! 몰랐어요. 조심할게요. |
| 住民 | いえいえ、よろしくお願いします。 | 아니에요, 잘 부탁드려요. |

**불만 표현의 쿠션**: 「言いにくいんですが」(말하기 어렵지만) · 「～していただけると助かります」(~해 주시면 도움이 됩니다) · 「ちょっと困っていまして」(좀 곤란해서요) — 직접 「やめてください」라고 하기보다 부드럽게 전합니다.

### 확인 문제

**Q1.** 일본식 거절의 3단계 구조는?

<details><summary>정답 보기</summary>

① 감사·사과 → ② 이유(흐리기) → ③ 대안·다음 기회

</details>

**Q2.** 반대 의견을 부드럽게 시작하는 표현 두 가지.

<details><summary>정답 보기</summary>

</details>
