# U63. 비즈니스 기본 — 첫인사·명함·호칭·사내 대화

### 오늘의 목표

- 첫 출근·거래처 첫 방문에서 자기소개를 할 수 있다
- 명함을 주고받는 순서와 말을 안다
- 사내 호칭(さん·役職)과 사외 호칭(様·御社)을 구별할 수 있다
- 報連相(보고·연락·상담)의 기본 문장을 말할 수 있다

### 첫 출근 인사

| 화자 | 대사 | 해석 |
|---|---|---|
| キム | 本日からお世話になります、キム・ジウと申します。 | 오늘부터 신세 지게 된 김지우라고 합니다. |
| キム | 前職では韓国のIT企業で、システム開発を担当しておりました。 | 전 직장에서는 한국 IT 기업에서 시스템 개발을 담당했습니다. |
| キム | 日本での勤務は初めてで、至らない点も多いかと存じますが、一日も早くお役に立てるよう努めてまいります。 | 일본 근무는 처음이라 부족한 점이 많겠지만 하루라도 빨리 도움이 되도록 노력하겠습니다. |
| キム | どうぞよろしくお願いいたします。 | 잘 부탁드립니다. |
| 部長 | キムさん、よろしくね。分からないことは何でも聞いてください。 | 김 씨, 잘 부탁해요. 모르는 건 뭐든 물어보세요. |

**핵심 표현**: 「お世話になります」(신세 지겠습니다 — 첫인사의 정석) · 「至らない点」(부족한 점) · 「～てまいります」(~해 나가겠습니다, 겸양)

### 명함 교환 — 순서와 말

| 순서 | 동작 | 말 |
|---|---|---|
| 1 | 일어서서, 테이블을 사이에 두지 않고 상대 앞으로 | — |
| 2 | 아랫사람·방문자가 먼저, 상대가 읽을 수 있는 방향으로 두 손으로 | 「〇〇社の キムと申します。よろしくお願いいたします。」 |
| 3 | 상대 명함은 두 손으로, 회사 로고·이름을 손가락으로 가리지 않게 | 「頂戴いたします。」 |
| 4 | 이름 읽기가 어려우면 그 자리에서 확인 | 「失礼ですが、何とお読みすればよろしいでしょうか。」 |
| 5 | 받은 명함은 앉은 뒤 명함 지갑 위에 올려 두고, 미팅 중 테이블 위에 둠 | — |

[교육용 설명] 받은 명함을 바로 주머니에 넣거나 그 위에 메모하는 것은 실례입니다. 여러 명이면 앉은 순서대로 테이블에 늘어놓아 이름을 확인합니다.

### 호칭 — 사내와 사외

| 대상 | 사내에서 부를 때 | 사외 사람에게 말할 때 |
|---|---|---|
| 우리 회사 사장 | 社長 / 山田社長 | 社長の山田 / 弊社の山田 |
| 우리 부장 | 部長 / 田中部長 | 部長の田中 / 田中 |
| 우리 동료 | 佐藤さん | 佐藤 |
| 상대 회사 사람 | — | 鈴木様 / 鈴木部長 |
| 상대 회사 | — | 御社(말) / 貴社(글) |
| 우리 회사 | うちの会社 | 弊社 / 当社 |

- 「部長さん」은 이중 높임처럼 들려 사내에서는 쓰지 않습니다. 「田中部長」 또는 「部長」.
- 메일 받는 사람 이름 뒤에 様, 부서·회사 앞으로 보낼 때는 御中: 「営業部 御中」.

### 報連相 — 보고·연락·상담

| 종류 | 표현 | 해석 |
|---|---|---|
| 보고 | 部長、〇〇の件でご報告があります。今、お時間よろしいでしょうか。 | 부장님, ○○ 건으로 보고드릴 게 있습니다. 지금 시간 괜찮으십니까? |
| 결론부터 | 結論から申し上げますと、契約は来月に延期になりました。 | 결론부터 말씀드리면 계약은 다음 달로 연기되었습니다. |
| 진척 | 現在、八割ほど進んでおります。金曜日には完成する見込みです。 | 현재 80% 정도 진행되었습니다. 금요일에는 완성될 전망입니다. |
| 연락 | 明日は10時から A社で打ち合わせのため、直行いたします。 | 내일은 10시부터 A사 미팅이라 바로 그쪽으로 출근하겠습니다. |
| 상담 | ご相談したいことがあるのですが、少しよろしいでしょうか。 | 상의드리고 싶은 게 있는데 잠시 괜찮으십니까? |
| 문제 보고 | 申し訳ございません。発注数を間違えてしまいました。 | 죄송합니다. 발주 수량을 잘못 넣었습니다. |
| 대응 제안 | すでに先方には連絡済みで、明日、正しい数を再送する予定です。 | 이미 상대 쪽에는 연락했고, 내일 올바른 수량을 다시 보낼 예정입니다. |

[교육용 설명] 일본 상사가 가장 중시하는 것이 **나쁜 소식일수록 빨리** 보고하는 것입니다. 보고는 「結論 → 経緯(경위) → 対応(대응)」 순서로 하세요.

### 사내 대화 — 업무 부탁과 확인

| 화자 | 대사 | 해석 |
|---|---|---|
| 先輩 | キムさん、ちょっといい? この資料、明日の会議までに英訳お願いできる? | 김 씨, 잠깐 괜찮아? 이 자료 내일 회의까지 영어로 번역 부탁할 수 있어? |
| キム | はい、承知しました。何時までに必要ですか。 | 네, 알겠습니다. 몇 시까지 필요하세요? |
| 先輩 | 会議が10時だから、9時半までにもらえると助かる。 | 회의가 10시니까 9시 반까지 주면 고마워. |
| キム | かしこまりました。一点確認ですが、表の数字も訳しますか。 | 알겠습니다. 한 가지 확인할 게 있는데, 표의 숫자도 번역할까요? |
| 先輩 | 数字はそのままでいいよ。 | 숫자는 그대로 두면 돼. |
| キム | 分かりました。できましたら、メールでお送りします。 | 알겠습니다. 다 되면 메일로 보내 드리겠습니다. |

**Q1.** 첫 출근 인사의 정석 첫마디는?

</details>

# U64. 전화 응대

### 오늘의 목표

- 회사 전화를 받고 이름·용건을 확인할 수 있다
- 담당자가 부재일 때 전언을 받을 수 있다
- 거래처에 전화를 걸어 담당자를 찾고 용건을 말할 수 있다
- 숫자·이름을 복창하여 실수를 막을 수 있다

### 전화 받기 — 기본 흐름

| 화자 | 대사 | 해석 |
|---|---|---|
| キム | はい、ミライ商事でございます。 | 네, 미라이상사입니다. |
| 相手 | わたくし、青山物産の鈴木と申しますが、営業部の田中様はいらっしゃいますか。 | 저는 아오야마물산의 스즈키라고 합니다만, 영업부 다나카 님 계십니까? |
| キム | 青山物産の鈴木様でいらっしゃいますね。いつもお世話になっております。 | 아오야마물산의 스즈키 님이시군요. 늘 신세 지고 있습니다. |
| キム | 田中でございますね。ただいま確認いたしますので、少々お待ちください。 | 다나카 말씀이시죠. 지금 확인하겠으니 잠시 기다려 주십시오. |
| キム | (保留) お待たせいたしました。田中に代わります。 | (보류 후) 오래 기다리셨습니다. 다나카를 바꿔 드리겠습니다. |

**포인트**
- 회사 전화는 「もしもし」 대신 「はい、〇〇でございます」로 받습니다.
- 3번 이상 울린 뒤 받으면 「お待たせいたしました」를 먼저.
- 상대 이름·회사를 반드시 복창합니다.

### 담당자가 부재일 때

| 상황 | 대사 | 해석 |
|---|---|---|
| 자리 비움 | 申し訳ございません。田中はただいま席を外しております。 | 죄송합니다. 다나카는 지금 자리를 비웠습니다. |
| 회의 중 | あいにく田中は会議中でございます。 | 공교롭게도 다나카는 회의 중입니다. |
| 외출 | 田中は外出しておりまして、15時に戻る予定です。 | 다나카는 외출 중이며 15시에 돌아올 예정입니다. |
| 휴가 | 田中は本日お休みをいただいております。 | 다나카는 오늘 휴가입니다. |
| 다른 통화 | 田中はただいま他の電話に出ております。 | 다나카는 지금 다른 전화를 받고 있습니다. |
| 제안 1 | 戻りましたら、こちらからお電話するよう申し伝えます。 | 돌아오면 이쪽에서 전화드리도록 전하겠습니다. |
| 제안 2 | よろしければ、ご用件を承りますが。 | 괜찮으시면 용건을 받아 두겠습니다만. |
| 연락처 | 念のため、お電話番号を伺ってもよろしいでしょうか。 | 혹시 모르니 전화번호를 여쭤봐도 될까요? |
| 복창 | 復唱いたします。03-1234-5678、青山物産の鈴木様でございますね。 | 복창하겠습니다. 03-1234-5678, 아오야마물산의 스즈키 님이시죠. |
| 마무리 | 私、キムが承りました。失礼いたします。 | 저 김이 받았습니다. 실례하겠습니다. |

**전언 메모 형식**: 誰から(누가) · いつ(언제) · 用件(용건) · 折り返しの要否(회신 필요 여부) · 連絡先(연락처) · 受けた人(받은 사람)

### 전화 걸기

| 화자 | 대사 | 해석 |
|---|---|---|
| キム | お世話になっております。ミライ商事のキムと申します。 | 신세 지고 있습니다. 미라이상사의 김이라고 합니다. |
| キム | 恐れ入りますが、営業部の鈴木様はいらっしゃいますでしょうか。 | 송구합니다만 영업부 스즈키 님 계십니까? |
| 受付 | 鈴木でございますね。少々お待ちください。 | 스즈키 말씀이시죠. 잠시만 기다려 주십시오. |
| 鈴木 | お電話代わりました、鈴木です。 | 전화 바꿨습니다, 스즈키입니다. |
| キム | お忙しいところ恐れ入ります。来週のお打ち合わせの件でお電話いたしました。今、少しお時間よろしいでしょうか。 | 바쁘신 와중에 송구합니다. 다음 주 미팅 건으로 전화드렸습니다. 지금 잠시 시간 괜찮으십니까? |
| 鈴木 | はい、大丈夫ですよ。 | 네, 괜찮습니다. |
| キム | 水曜日の14時からとお約束しておりましたが、木曜日の同じ時間に変更させていただくことは可能でしょうか。 | 수요일 14시로 약속드렸는데, 목요일 같은 시간으로 변경하는 것이 가능할까요? |
| 鈴木 | 木曜日ですね。大丈夫です。 | 목요일이요. 괜찮습니다. |
| キム | ありがとうございます。ご迷惑をおかけして申し訳ございません。では、木曜日14時に伺います。失礼いたします。 | 감사합니다. 폐를 끼쳐 죄송합니다. 그럼 목요일 14시에 찾아뵙겠습니다. 실례하겠습니다. |

[교육용 설명] 전화를 끊을 때는 **건 쪽이 먼저** 끊는 것이 원칙이지만, 상대가 손님·윗사람이면 상대가 끊은 것을 확인하고 조용히 끊습니다.

### 잘 안 들릴 때·모를 때

| 상황 | 대사 | 해석 |
|---|---|---|
| 잘 안 들림 | 恐れ入りますが、お電話が少し遠いようです。 | 송구합니다만 전화가 좀 잘 안 들리는 것 같습니다. |
| 다시 | もう一度お名前をお伺いしてもよろしいでしょうか。 | 성함을 한 번 더 여쭤봐도 될까요? |
| 철자 | お名前の漢字は、どのように書きますか。 | 성함 한자는 어떻게 쓰십니까? |
| 모르는 내용 | 私では分かりかねますので、担当の者からご連絡差し上げます。 | 제가 알기 어려워 담당자가 연락드리겠습니다. |
| 잘못 건 전화 | 失礼ですが、何番におかけでしょうか。 | 실례지만 몇 번으로 거셨습니까? |

**Q1.** 회사 전화를 받을 때 첫마디는?

</details>

# U65. 회의·발표

### 오늘의 목표

- 회의를 진행(시작·의제·정리)하는 표현을 쓸 수 있다
- 의견을 내고, 질문하고, 동의·이견을 부드럽게 말할 수 있다
- 프레젠테이션의 도입·전개·마무리 표현을 쓸 수 있다
- 질의응답에서 모르는 질문에 대처할 수 있다

### 회의 진행

| 단계 | 표현 | 해석 |
|---|---|---|
| 시작 | それでは、定刻になりましたので、会議を始めます。 | 그럼 정각이 되었으니 회의를 시작하겠습니다. |
| 의제 | 本日の議題は三点です。 | 오늘 의제는 세 가지입니다. |
| 진행 | まず、先月の売上について、佐藤さんからご報告をお願いします。 | 먼저 지난달 매출에 대해 사토 씨가 보고해 주십시오. |
| 의견 요청 | この件について、ご意見のある方はいらっしゃいますか。 | 이 건에 대해 의견 있으신 분 계십니까? |
| 시간 | 時間が押していますので、次の議題に移ります。 | 시간이 밀리고 있으니 다음 의제로 넘어가겠습니다. |
| 정리 | 本日の決定事項を確認します。 | 오늘 결정 사항을 확인하겠습니다. |
| 과제 | 次回までの宿題は、A案の費用の試算です。担当は木村さん、期限は来週の金曜日です。 | 다음까지의 과제는 A안의 비용 산정입니다. 담당은 기무라 씨, 기한은 다음 주 금요일입니다. |
| 종료 | 以上で本日の会議を終わります。お疲れ様でした。 | 이상으로 오늘 회의를 마치겠습니다. 수고하셨습니다. |

### 의견·질문·이견

| 기능 | 표현 | 해석 |
|---|---|---|
| 의견 | 私としては、B案のほうが現実的ではないかと考えております。 | 저로서는 B안이 더 현실적이지 않을까 생각합니다. |
| 근거 | と申しますのも、B案は既存のシステムを活用できるからです。 | 왜냐하면 B안은 기존 시스템을 활용할 수 있기 때문입니다. |
| 질문 | 一点、質問よろしいでしょうか。 | 한 가지 질문해도 될까요? |
| 확인 | 確認させていただきたいのですが、予算の上限はいくらでしょうか。 | 확인하고 싶은데요, 예산 상한은 얼마입니까? |
| 동의 | おっしゃる通りだと思います。 | 말씀하신 대로라고 생각합니다. |
| 보충 | 今のご意見に一点補足させてください。 | 지금 의견에 한 가지 보충하겠습니다. |
| 이견 | ご指摘の点はもっともですが、コストの面から見ると、少し懸念があります。 | 지적하신 점은 지당하지만 비용 측면에서 보면 조금 우려가 있습니다. |
| 대안 | 代案として、まず小規模で試してみるのはいかがでしょうか。 | 대안으로 먼저 소규모로 시험해 보는 건 어떨까요? |
| 보류 | この件は一度持ち帰って、社内で検討させてください。 | 이 건은 일단 가져가서 사내에서 검토하겠습니다. |

# U66. 제안·협상·거절·사과

### 오늘의 목표

- 거래처에 제안하고 조건(가격·납기)을 조율할 수 있다
- 상대 요구를 완곡하게 거절하고 대안을 낼 수 있다
- 클레임에 사과하고 대응을 설명할 수 있다
- 협상을 마무리하고 합의 내용을 확인할 수 있다

### 제안하기

| 화자 | 대사 | 해석 |
|---|---|---|
| キム | 本日は、御社の物流コスト削減について、ご提案をお持ちしました。 | 오늘은 귀사의 물류비 절감에 대해 제안을 가지고 왔습니다. |
| キム | 現在、配送ルートが重複している区間が多く見られます。 | 현재 배송 경로가 중복되는 구간이 많이 보입니다. |
| キム | 弊社のシステムを導入いただければ、年間で約15%のコスト削減が見込めます。 | 저희 시스템을 도입하시면 연간 약 15% 비용 절감이 예상됩니다. |
| 相手 | なるほど。導入にはどのくらいの期間がかかりますか。 | 그렇군요. 도입에는 어느 정도 기간이 걸립니까? |
| キム | 標準的なケースで、約二か月を想定しております。 | 표준적인 경우 약 2개월을 상정하고 있습니다. |

### 조건 조율 — 가격·납기

| 기능 | 표현 | 해석 |
|---|---|---|
| 가격 요청 | もう少しお値段のほう、ご相談させていただけないでしょうか。 | 가격을 조금 더 상의드릴 수는 없을까요? |
| 조건부 수락 | ご発注数を千個以上にしていただけるのであれば、5%お値引きいたします。 | 발주 수량을 천 개 이상으로 해 주신다면 5% 할인해 드리겠습니다. |
| 납기 | 納期を一週間早めていただくことは可能でしょうか。 | 납기를 일주일 앞당겨 주실 수 있을까요? |
| 어려움 | 正直に申し上げますと、その価格ですと弊社としては厳しい状況です。 | 솔직히 말씀드리면 그 가격이면 저희로서는 어려운 상황입니다. |
| 절충 | では、間を取って、3%ではいかがでしょうか。 | 그럼 중간을 잡아서 3%는 어떠십니까? |
| 결정권 | 私の一存ではお答えしかねますので、上の者と相談いたします。 | 제 판단만으로는 답변드리기 어려워 상사와 상의하겠습니다. |
| 합의 | では、その条件で進めさせていただきます。 | 그럼 그 조건으로 진행하겠습니다. |

### 완곡하게 거절하기

| 단계 | 표현 | 해석 |
|---|---|---|
| ① 감사 | 貴重なご提案をいただき、ありがとうございます。 | 귀중한 제안을 주셔서 감사합니다. |
| ② 검토 사실 | 社内で慎重に検討いたしましたが…… | 사내에서 신중히 검토했습니다만…… |
| ③ 거절 | 誠に残念ながら、今回は見送らせていただくことになりました。 | 대단히 아쉽지만 이번에는 보류하게 되었습니다. |
| ④ 이유(간단히) | 現在、予算の都合がつかない状況でございまして。 | 현재 예산 사정이 여의치 않은 상황이라서요. |
| ⑤ 관계 유지 | また機会がございましたら、ぜひよろしくお願いいたします。 | 또 기회가 있으면 꼭 잘 부탁드립니다. |

**거절에 쓰는 말**: 「見送らせていただきます」(보류하겠습니다 = 거절) · 「ご要望に沿いかねます」(요청에 부응하기 어렵습니다) · 「いたしかねます」(하기 어렵습니다) · 「今回はご縁がなかったということで」(이번에는 인연이 없었던 것으로)

### 클레임 대응 — 사과와 설명

| 화자 | 대사 | 해석 |
|---|---|---|
| 顧客 | 昨日届いた商品、数が足りないんですけど。 | 어제 도착한 상품 수량이 모자라는데요. |
| キム | 大変申し訳ございません。ご迷惑をおかけしております。 | 대단히 죄송합니다. 폐를 끼쳐 드리고 있습니다. |
| キム | 恐れ入りますが、ご注文番号をお伺いできますでしょうか。 | 송구합니다만 주문 번호를 여쭤봐도 될까요? |
| 顧客 | A-2045です。100個頼んだのに、80個しかないんですよ。 | A-2045요. 100개 주문했는데 80개밖에 없어요. |
| キム | 確認いたしました。こちらの梱包ミスで、20個が別便になっておりました。 | 확인했습니다. 저희 포장 실수로 20개가 별도 배송으로 되어 있었습니다. |
| キム | 本日中に発送し、明日の午前中にはお届けいたします。 | 오늘 중으로 발송해 내일 오전 중에는 도착하도록 하겠습니다. |
| キム | 今後このようなことがないよう、確認体制を見直してまいります。誠に申し訳ございませんでした。 | 앞으로 이런 일이 없도록 확인 체계를 재검토하겠습니다. 대단히 죄송했습니다. |

[교육용 설명] 클레임 대응의 순서: **① 사과 → ② 사실 확인(질문) → ③ 원인 설명(변명이 아니라 사실) → ④ 대응책과 일정 → ⑤ 재발 방지 → ⑥ 다시 사과**. 처음부터 원인 설명이나 변명을 하면 상대를 더 화나게 합니다.

### 협상 마무리 — 합의 확인

| 표현 | 해석 |
|---|---|
| 本日の内容を整理させていただきます。 | 오늘 내용을 정리하겠습니다. |

| 契約書の案は来週お送りしますので、ご確認いただけますと幸いです。 | 계약서 초안은 다음 주에 보내 드리니 확인해 주시면 감사하겠습니다. |

# U67. 비즈니스 메일·문서

### 오늘의 목표

- 일본 비즈니스 메일의 형식(제목·받는 사람·인사·본문·맺음·서명)을 갖춰 쓸 수 있다
- 의뢰·감사·사과·일정 조율·리마인드 메일을 쓸 수 있다
- 쿠션 언어와 정형 표현으로 정중한 문장을 만들 수 있다

### 메일의 뼈대

```
件名：【ご依頼】新製品カタログ送付のお願い（ミライ商事 キム）

株式会社青山物産
営業部　鈴木様

いつもお世話になっております。
ミライ商事のキムでございます。

（本文：用件 → 詳細 → お願い）

お忙しいところ恐縮ですが、ご確認のほど
よろしくお願いいたします。

――――――――――――――
ミライ商事株式会社　海外営業部
キム・ジウ
TEL：03-1234-5678
Mail：kim@mirai-shoji.example
――――――――――――――
```

| 부분 | 규칙 |
|---|---|
| 件名(제목) | 용건이 한눈에 보이게. 【ご依頼】【ご報告】【至急】 같은 머리표 + 회사명·이름 |
| 宛名(받는 사람) | 회사명(株式会社 생략 금지) → 부서 → 이름 + 様 |
| 첫 인사 | 사외: いつもお世話になっております。 / 처음: 初めてご連絡いたします。 / 사내: お疲れ様です。 |
| 이름 밝히기 | 〇〇社の〇〇でございます。 |
| 본문 | 결론(용건) 먼저, 한 문단 2~3줄, 날짜·수량은 별도 줄로 |
| 맺음 | よろしくお願いいたします。(정중 + 申し上げます) |
| 서명 | 회사·부서·이름·연락처 |

### 상황별 메일 문장

**의뢰(お願い)**

| 일본어 | 해석 |
|---|---|
| 新製品のカタログを3部お送りいただけますでしょうか。 | 신제품 카탈로그를 3부 보내 주실 수 있겠습니까? |
| 大変恐縮ですが、今週金曜日までにご回答いただけますと幸いです。 | 대단히 송구합니다만 이번 주 금요일까지 회답 주시면 감사하겠습니다. |
| お手数をおかけしますが、添付の書類にご署名のうえ、ご返送ください。 | 번거로우시겠지만 첨부 서류에 서명하신 후 반송해 주십시오. |

**감사(お礼)**

| 일본어 | 해석 |
|---|---|
| 本日はお忙しいところ、お時間をいただき誠にありがとうございました。 | 오늘 바쁘신 와중에 시간을 내주셔서 진심으로 감사했습니다. |
| 迅速にご対応いただき、大変助かりました。 | 신속하게 대응해 주셔서 큰 도움이 되었습니다. |
| いただいたご意見は、今後の改善に活かしてまいります。 | 주신 의견은 앞으로의 개선에 활용하겠습니다. |

**사과(お詫び)**

| 일본어 | 해석 |
|---|---|
| ご返信が遅くなり、大変申し訳ございません。 | 회신이 늦어 대단히 죄송합니다. |
| 先日お送りした資料に誤りがございました。訂正版を添付いたします。 | 일전에 보내 드린 자료에 오류가 있었습니다. 수정본을 첨부합니다. |
| 多大なるご迷惑をおかけしましたことを、心よりお詫び申し上げます。 | 큰 폐를 끼친 것을 진심으로 사과드립니다. |

**일정 조율(日程調整)**

| 일본어 | 해석 |
|---|---|
| つきましては、打ち合わせのお時間をいただきたく、ご連絡いたしました。 | 그래서 미팅 시간을 내주셨으면 하여 연락드렸습니다. |
| 下記の日程でご都合のよい日時はございますでしょうか。 | 아래 일정 중 편하신 날짜와 시간이 있으십니까? |
| ・10月15日（水）14:00～17:00 / ・10月16日（木）10:00～12:00 | 10월 15일(수) 14~17시 / 10월 16일(목) 10~12시 |
| 上記以外でも調整いたしますので、お知らせください。 | 위 일정 외에도 조정하겠으니 알려 주십시오. |

**리마인드(催促) — 부드럽게 재촉하기**

| 일본어 | 해석 |
|---|---|
| 先日お願いしておりました見積書の件、その後いかがでしょうか。 | 일전에 부탁드렸던 견적서 건은 그 후 어떻게 되셨는지요. |
| 行き違いでご送付いただいておりましたら、ご容赦ください。 | 엇갈려 이미 보내 주셨다면 양해 부탁드립니다. |

[교육용 설명] 재촉 메일에 「行き違いでしたらご容赦ください」를 붙이면 '혹시 이미 보냈다면 죄송'이라는 배려가 들어가 상대가 기분 상하지 않습니다.

### 자주 쓰는 정형 표현

| 표현 | 뜻 |
|---|---|

| ご確認のほどよろしくお願いいたします | 확인 부탁드립니다 |
| 取り急ぎご連絡まで | 우선 급히 연락드립니다(짧은 메일 맺음) |
| 引き続きよろしくお願いいたします | 앞으로도 잘 부탁드립니다 |
| 何卒よろしくお願い申し上げます | 아무쪼록 잘 부탁드립니다(가장 정중) |
| 標記の件につきまして | 제목의 건에 대하여 |
| ご不明な点がございましたら、お気軽にお問い合わせください | 불명확한 점이 있으면 편히 문의해 주십시오 |
| ご多忙のところ恐縮ですが | 바쁘신 와중에 송구합니다만 |
| 末筆ながら、皆様のご健勝をお祈り申し上げます | 끝으로 여러분의 건승을 기원합니다(격식 있는 맺음) |

**Q1.** 거래처 메일 첫 인사 두 줄을 쓰세요(회사: ミライ商事, 이름: キム).

# U69. 접대·회식·잡담

### 오늘의 목표

- 회식 자리의 기본 매너(건배·술 따르기·자리)를 안다
- 스몰토크(날씨·출신·취미·음식)로 대화를 이어 갈 수 있다
- 접대에서 감사·칭찬·작별 인사를 할 수 있다
- 회식 다음 날의 인사를 할 수 있다

### 회식 매너

| 장면 | 매너·표현 | 해석 |
|---|---|---|
| 자리 | 출입구에서 먼 자리가 상석(上座), 가까운 자리가 하석(下座). 아랫사람은 하석에. | — |
| 첫 잔 | とりあえずビールで! | 일단 맥주로! (첫 주문의 단골) |
| 건배 | それでは、プロジェクトの成功を祝して、乾杯! | 그럼 프로젝트의 성공을 축하하며, 건배! |
| 따르기 | どうぞ。/ お注ぎします。 | 드세요. / 따라 드리겠습니다. |
| 받기 | ありがとうございます。(잔을 두 손으로 들어 받음) | 감사합니다. |
| 사양 | 私、お酒が弱いので、ウーロン茶で失礼します。 | 제가 술이 약해서 우롱차로 하겠습니다. |
| 음식 권유 | お料理、取り分けましょうか。 | 요리 덜어 드릴까요? |
| 마무리 | そろそろお開きにしましょうか。 | 슬슬 마칠까요? |

[교육용 설명] 일본에서는 상대 잔이 비기 전에 채워 주는 것이 예의이고, 자기 잔을 직접 채우기보다 서로 따라 줍니다. 술을 못 마셔도 첫 건배는 잔에 입만 대거나 소프트드링크로 참여하면 됩니다.

### 스몰토크 — 대화를 여는 질문

| 주제 | 질문 | 해석 |
|---|---|---|
| 날씨 | 最近、急に寒くなりましたね。 | 요즘 갑자기 추워졌네요. |
| 출신 | ご出身はどちらですか。 | 고향이 어디세요? |
| 고향 이야기 | 大阪ですか。食べ物がおいしいところですよね。 | 오사카요? 음식이 맛있는 곳이죠. |
| 휴일 | 休みの日は何をされているんですか。 | 쉬는 날에는 뭐 하세요? |
| 취미 | ゴルフをされるんですね。どのくらい続けていらっしゃるんですか。 | 골프를 치시는군요. 얼마나 하셨어요? |
| 음식 | 韓国料理は召し上がりますか。 | 한국 요리는 드세요? |
| 한국 화제 | 最近、韓国ドラマにはまっていまして。おすすめはありますか。 | 요즘 한국 드라마에 빠져 있어서요. 추천할 만한 거 있어요? |
| 여행 | 日本でおすすめの旅行先はありますか。 | 일본에서 추천하는 여행지 있어요? |

[교육용 설명] 처음 만난 자리에서는 나이·결혼·연봉·정치·종교 이야기는 피하는 것이 무난합니다. 날씨·음식·출신지·여행은 안전한 화제입니다.

### 대화 — 거래처 접대

| 화자 | 대사 | 해석 |
|---|---|---|
| 鈴木 | キムさん、日本の生活にはもう慣れましたか。 | 김 씨, 일본 생활에는 이제 익숙해지셨어요? |
| キム | おかげさまで、だいぶ慣れました。ただ、満員電車だけはまだ苦手で……。 | 덕분에 꽤 익숙해졌습니다. 다만 만원 전철만은 아직 힘들어서요……. |
| 鈴木 | ははは、あれは日本人でも慣れませんよ。 | 하하하, 그건 일본인도 익숙해지지 않아요. |

| 鈴木 | ええ、魚がおいしいので、大事なお客様をお連れするときに使っています。 | 네, 생선이 맛있어서 중요한 손님을 모실 때 이용해요. |
| キム | 光栄です。本当においしいです。 | 영광입니다. 정말 맛있습니다. |
| 鈴木 | 次はぜひ、キムさんおすすめの韓国料理のお店に連れて行ってください。 | 다음에는 꼭 김 씨가 추천하는 한국 요리 가게에 데려가 주세요. |

### 작별과 다음 날 인사

| 즐거웠음 | とても楽しい時間を過ごさせていただきました。 | 정말 즐거운 시간을 보냈습니다. |

| 다음 날(메일) | 昨夜は貴重なお時間をいただき、誠にありがとうございました。 | 어젯밤 귀중한 시간을 내주셔서 진심으로 감사했습니다. |

[교육용 설명] 일본에서는 대접받은 **다음 날 다시 한번 감사 인사**를 하는 것이 중요한 매너입니다. 직접 만나면 「昨日はごちそうさまでした」, 거래처라면 오전 중에 감사 메일을 보냅니다.
