# U21. 경어 완전 정리

### 오늘의 목표

- 경어의 5분류(존경어·겸양어Ⅰ·겸양어Ⅱ·정중어·미화어)를 설명할 수 있다
- 자주 쓰는 동사 20개의 존경어·겸양어를 바로 말할 수 있다
- 회사 안·밖(ウチ·ソト)에 따라 높임의 방향을 바꿀 수 있다
- 쿠션 언어와 바른 경어로 부탁·거절·사과를 할 수 있다
- 자주 틀리는 경어(이중 경어, バイト敬語)를 고칠 수 있다

### 경어의 5분류

일본 문화청 「敬語の指針」(2007)은 경어를 다섯 가지로 나눕니다 [S16].

| 분류 | 하는 일 | 예 |
|---|---|---|
| 존경어 | **상대·제3자(손윗사람)의 행동·상태**를 높임 | いらっしゃる, おっしゃる, お使いになる, ご説明くださる |
| 겸양어Ⅰ | **나의 행동이 향하는 상대**를 높임 | 伺う(찾아뵙다), 申し上げる, お届けする, ご案内する |
| 겸양어Ⅱ (丁重語) | **나의 행동을 정중하게** 말해 듣는 사람에게 예의 | 参る(가다·오다), 申す(말하다), いたす(하다), おる(있다) |
| 정중어 | 듣는 사람에게 공손하게 | です, ます, ございます |
| 미화어 | 말을 아름답게 | お茶, お酒, ご飯, お手洗い |

[기술근거] 겸양어Ⅰ과 Ⅱ의 차이: 「先生の お宅に 伺います」(선생님 댁을 찾아뵙습니다 — 선생님을 높임, Ⅰ) / 「明日 東京へ 参ります」(내일 도쿄에 갑니다 — 도쿄를 높이는 게 아니라 듣는 사람에게 정중, Ⅱ). 「東京へ 伺います」는 어색합니다 [S16].

### 만드는 공식

| 공식 | 종류 | 예 |
|---|---|---|
| お + ます형 + になる | 존경 | お帰りになる, お書きになる |
| ご + 한자어 + になる | 존경 | ご利用になる, ご出席になる |
| ～れる・～られる | 존경(가벼움) | 行かれる, 来られる, 書かれる |
| お + ます형 + ください / ご + 한자어 + ください | 존경 부탁 | お待ちください, ご確認ください |
| お + ます형 + する(いたす) | 겸양Ⅰ | お持ちする, お送りいたします |
| ご + 한자어 + する(いたす) | 겸양Ⅰ | ご案内します, ご連絡いたします |
| ～(さ)せていただく | 겸양(허락을 받아 하는 느낌) | 説明させて いただきます |

- 고유어(和語)는 お, 한자어(漢語)는 ご가 원칙: お名前·お電話(예외)·ご住所·ご連絡.
- 특별 경어(위 표)가 있는 동사는 공식보다 특별 경어를 씁니다: 「お言いになる」(×) → おっしゃる.

### ウチ·ソト — 누구를 높이는가

일본 경어는 **나이·직급보다 '안(ウチ)과 밖(ソト)'이 우선**입니다. 회사 밖 사람(거래처·손님)에게 말할 때, 우리 회사 사람은 사장이라도 높이지 않습니다.

| 상황 | ○ | × |
|---|---|---|
| 거래처의 전화: 「部長さんは いらっしゃいますか」 | 「部長の 田中は ただいま 席を 外して おります」 | 「田中部長は 席を 外して いらっしゃいます」 |
| 손님에게 사장 소개 | 「弊社 社長の 山田で ございます」 | 「山田社長で いらっしゃいます」 |
| 사내에서 부장에게 | 「部長、社長が お呼びです」 | — |

- 회사 밖에서 자기 회사 사람은 **이름만 부르고(さん·役職 없이)** 겸양어를 씁니다: 「田中が 申して おりました」.
- 직급 + さん(部長さん)은 사내에서는 쓰지 않는 게 원칙. 「田中部長」 또는 「部長」.
- 상대 회사: 御社(おんしゃ, 말) / 貴社(きしゃ, 글). 우리 회사: 弊社(へいしゃ) / 当社(とうしゃ, 중립).

### 쿠션 언어 — 부탁·거절을 부드럽게

| 쿠션 언어 | 뜻 | 쓰는 장면 |
|---|---|---|
| 恐れ入りますが | 송구합니다만 | 부탁·질문 |
| 恐縮ですが | 죄송스럽습니다만 | 부탁 |
| お手数ですが / お手数を おかけしますが | 번거로우시겠지만 | 수고를 끼치는 부탁 |
| 差し支えなければ | 괜찮으시다면 | 개인 정보 묻기 |
| よろしければ | 괜찮으시면 | 권유 |
| あいにく | 공교롭게도 | 거절·부재 |
| 申し訳ございませんが | 죄송합니다만 | 거절·사과 |
| せっかくですが | 모처럼이지만 | 초대 거절 |
| 失礼ですが | 실례지만 | 이름·소속 묻기 |

| 예문 | 해석 |
|---|---|
| 恐れ入りますが、お名前を 伺っても よろしいでしょうか。 | 송구합니다만 성함을 여쭤봐도 될까요? |
| お手数ですが、こちらに ご記入ください。 | 번거로우시겠지만 여기에 기입해 주십시오. |
| あいにく 山田は 外出して おります。 | 공교롭게도 야마다는 외출 중입니다. |
| せっかくですが、その 日は 先約が ございまして…。 | 모처럼이지만 그날은 선약이 있어서요…. |

### 부탁의 정중도 사다리

같은 '써 주세요'도 상대와 상황에 따라 단계를 올립니다.

| 단계 | 표현 |
|---|---|
| 1 | 書いて ください。 |
| 2 | 書いて いただけますか。 |
| 3 | 書いて いただけませんか。 |
| 4 | お書き いただけますでしょうか。 |
| 5 | 恐れ入りますが、ご記入 いただけますでしょうか。 |
| 6 | お手数を おかけしますが、ご記入 いただけますと 幸いです。(메일) |

[교육용 설명] 부정 의문(いただけませんか)이 긍정 의문(いただけますか)보다 정중합니다. 「～していただけると 幸いです」(~해 주시면 감사하겠습니다)는 메일 부탁의 정석입니다(U67).

### 자주 틀리는 경어

| 틀린 말 | 문제 | 고친 말 |
|---|---|---|
| おっしゃられる | 이중 경어(おっしゃる + られる) | おっしゃる |
| ご覧になられる | 이중 경어 | ご覧になる |
| お伺いいたします | 이중 경어지만 관용적으로 허용되는 편 | 伺います (가장 안전) |
| ご苦労様です (상사에게) | 손윗사람이 아랫사람을 위로하는 말 | お疲れ様です |
| 了解しました (손님·상사에게) | 동등·아랫사람 느낌이라는 인식이 있음 | 承知しました / かしこまりました |
| 1万円から お預かりします | バイト敬語(편의점 말투) | 1万円 お預かりします |
| こちら コーヒーに なります | バイト敬語(なる는 '변화') | こちら コーヒーで ございます |
| 拝見させて いただきます | させていただく 과잉 | 拝見します |
| 社長が 申されました | 겸양어 + 존경 혼동 | 社長が おっしゃいました |
| 参られますか | 겸양어에 존경을 붙임 | いらっしゃいますか |
| 先生も 参りますか | 상대 행동에 겸양어 | 先生も いらっしゃいますか |

[교육용 설명] 「～させていただく」는 **상대의 허락을 받아 하는 일, 그 일로 내가 은혜를 입는 경우**에 맞습니다(「本日は 休ませて いただきます」 — 쉬게 해 주셔서 감사). 단순히 내가 하는 일에 남용하면 장황하고 어색하게 들립니다.

### 확인 문제

**Q2.** 거래처 전화에 우리 부장이 자리에 없을 때 바른 대답은?
