## JLPT 한눈에

일본어능력시험(JLPT)은 N5(가장 쉬움)부터 N1(가장 어려움)까지 다섯 단계입니다 [S01].

| 급수 | 공식 기준 요약 [S01] | 시험 영역 [S03] |
|---|---|---|
| N5 | 기본적인 일본어를 어느 정도 이해 | 언어지식(문자·어휘) · 언어지식(문법)·독해 · 청해 |
| N4 | 기본적인 일본어를 이해 | 위와 같음 |
| N3 | 일상적인 일본어를 어느 정도 이해 | 위와 같음 |
| N2 | 일상 + 폭넓은 장면의 일본어를 어느 정도 이해 | 언어지식(문자·어휘·문법)·독해 · 청해 |
| N1 | 폭넓은 장면에서 쓰이는 일본어를 이해 | 위와 같음 |

**합격 기준** [S04]: 총점 180점 만점에 N1 100점 · N2 90점 · N3 95점 · N4 90점 · N5 80점 이상, 그리고 **영역별 기준점**(과락)을 모두 넘어야 합니다. 점수는 정답 개수를 그대로 더한 값이 아니라 척도 점수입니다.

- 공식 예제 문제는 JLPT 사이트에서 무료로 볼 수 있습니다 [S05]. 이 사이트의 문제는 모두 자체 제작이며 공식 문제가 아닙니다.
- JLPT는 말하기·쓰기를 직접 시험하지 않습니다 [S02]. 그래서 회화 단원(U59–U69)을 따로 두었습니다.

## 한국어 화자의 강점과 함정

**강점**

- **어순이 같다**: 私は 学校に 行きます = 나는 학교에 갑니다. 조사(は·が·を·に)도 한국어 조사와 거의 1:1로 대응합니다.
- **한자어가 통한다**: 経済(けいざい, 경제)·準備(じゅんび, 준비)·関係(かんけい, 관계)처럼 한국 한자음을 알면 일본 음독을 추측할 수 있습니다. 어휘 표의 `한자음` 열과 U37 한자 읽기의 원리를 활용하세요.
- **경어 체계가 있다**: 높임말 감각이 있어 존경어·겸양어 구분을 빨리 익힙니다.

**함정** (단원마다 다시 짚습니다)

- **は와 が**를 '은/는'과 '이/가'에 기계적으로 대응시키면 틀리는 곳이 있습니다 (U03).
- **장음·촉음**: おばさん(아주머니)/おばあさん(할머니), きて(와서)/きって(우표)처럼 길이로 뜻이 바뀝니다 (U01).
- **어두의 탁음**: か와 が, た와 だ를 단어 첫소리에서 구별해야 합니다. 한국어의 ㄱ/ㄲ/ㅋ 구별과 기준이 다릅니다 (U01).
- **같은 한자어, 다른 뜻**: 勉強(공부), 留守(부재중), 大丈夫(괜찮다), 工夫(궁리)처럼 한국어와 뜻이 다른 한자어가 있습니다 (U49).
- **한자 읽기가 여러 개**: 生은 せい·しょう·いきる·うまれる·なま… 처럼 단어마다 읽기가 다릅니다. 한자 단원에서 읽기별 예시로 정리했습니다.

## 화면 사용법

- **읽음 체크**: 섹션을 다 읽으면 `읽음`을 누르세요. 홈 카드와 사이드바에 진도가 쌓이고, 연습문제의 **공부한 범위** 모드는 읽음 체크한 단원의 문제만 냅니다.
- **가림펜으로 외우기**: 필기 툴바의 가림펜으로 단어 표의 `뜻`·`읽기` 열을 칠하면 가려지고, 탭하면 보입니다. 단어·한자·문법 예문 해석 모두 이 방법으로 셀프 테스트하세요.
- **사이드바 묶음**: 왼쪽 목차의 묶음 제목(문법·어휘·한자…)을 누르면 접고 펼칩니다.
- **단어 사전**: 일본어, 읽기(히라가나), 한국어 뜻 어느 것으로도 검색됩니다. 단원 번호를 누르면 그 단어가 있는 단원으로 갑니다.
- **이름 로그인**: 처음 정한 이름이 아이디입니다. 다른 기기에서 같은 이름으로 들어오면 필기·진도가 이어집니다.

# U01. 문자와 발음

### 오늘의 목표

- 히라가나 46자와 가타카나 46자를 읽고 쓸 수 있다
- 탁음·반탁음·요음을 소리 낼 수 있다
- 장음·촉음·발음(ん)이 한 박자라는 것을 설명할 수 있다
- 외래어 가타카나 표기 규칙을 안다

### 일본어 문자 세 가지

일본어 문장에는 세 종류의 문자가 섞여 있습니다.

| 문자 | 예 | 쓰임 |
|---|---|---|
| 히라가나 | あいうえお | 조사·어미·고유어, 한자가 없는 말 |
| 가타카나 | アイウエオ | 외래어(コーヒー), 의성어, 강조 |
| 한자 | 日本・食べる | 단어의 뜻 부분(명사, 동사·형용사의 어간) |

> 私は 毎朝 コーヒーを 飲みます。 (나는 매일 아침 커피를 마십니다.)
> 한자 = 私·毎朝·飲 / 히라가나 = は·を·みます / 가타카나 = コーヒー

일본어는 띄어쓰기를 하지 않습니다. 한자와 가나가 섞여 있어서 어디서 단어가 끊기는지 보입니다. 이 사이트의 초급 예문은 읽기 쉽도록 띄어 쓴 곳이 있습니다.

### 히라가나 50음도

**한국어로 옮길 때 주의할 소리**

- う는 입술을 둥글게 내밀지 않는 '으'와 '우' 사이 소리입니다. す·つ·ぬ 등도 마찬가지.
- し = 시(shi), ち = 치(chi), つ = '쓰'와 '츠' 사이(tsu), ふ = 입술을 살짝 모아 부는 '후'(fu).
- ら행은 혀끝을 윗잇몸에 가볍게 튕기는 소리로, 한국어 '라'의 ㄹ과 거의 같습니다.
- を는 조사로만 쓰이고 お와 같은 '오'로 읽습니다. 조사 は는 '와', 조사 へ는 '에'로 읽습니다.

**헷갈리는 히라가나**: あ/お, い/り, う/ら, さ/ち, ぬ/め, ね/れ/わ, る/ろ, は/ほ — 공책에 짝을 지어 써 보세요.

### 탁음·반탁음

글자 오른쪽 위의 점 두 개(゛)는 **탁음**(울리는 소리), 동그라미(゜)는 **반탁음**(p 소리)입니다.

| | a | i | u | e | o |
|---|---|---|---|---|---|
| g | が ga | ぎ gi | ぐ gu | げ ge | ご go |
| z | ざ za | じ ji | ず zu | ぜ ze | ぞ zo |
| d | だ da | ぢ ji | づ zu | で de | ど do |
| b | ば ba | び bi | ぶ bu | べ be | ぼ bo |
| p | ぱ pa | ぴ pi | ぷ pu | ぺ pe | ぽ po |

- ぢ·づ는 じ·ず와 소리가 같습니다. 鼻血(はなぢ, 코피), 続く(つづく, 계속되다)처럼 원래 ち·つ가 탁음이 된 단어에서만 씁니다.
- **한국어 화자 주의**: が의 g는 목청이 울리는 소리입니다. 한국어 '가'를 단어 첫머리에서 발음하면 k에 가깝게 들려 か로 오해받기 쉽습니다. 「が」 앞에 아주 짧게 '응'을 붙인다는 느낌으로 연습하세요. 반대로 か·た를 단어 중간에서 발음할 때 '가·다'처럼 울리지 않게 주의합니다(わたし는 '와다시'가 아닌 '와타시').

### 요음

い단 글자(き·し·ち…) 뒤에 작은 ゃ·ゅ·ょ를 붙이면 한 박자로 합쳐집니다.

| | ゃ | ゅ | ょ |

| き | きゃ kya | きゅ kyu | きょ kyo |
| し | しゃ sha | しゅ shu | しょ sho |
| ち | ちゃ cha | ちゅ chu | ちょ cho |
| に | にゃ nya | にゅ nyu | にょ nyo |
| ひ | ひゃ hya | ひゅ hyu | ひょ hyo |
| み | みゃ mya | みゅ myu | みょ myo |
| り | りゃ rya | りゅ ryu | りょ ryo |
| ぎ | ぎゃ gya | ぎゅ gyu | ぎょ gyo |
| じ | じゃ ja | じゅ ju | じょ jo |
| び | びゃ bya | びゅ byu | びょ byo |
| ぴ | ぴゃ pya | ぴゅ pyu | ぴょ pyo |

**크기에 주의**: びょういん(美容院이 아닌 病院, 병원 — 4박자) vs びよういん(美容院, 미용실 — 5박자). 작은 ょ인지 큰 よ인지로 단어가 바뀝니다.

### 박자(모라) — 일본어 리듬의 기본

일본어는 **글자 하나(요음은 두 글자 한 묶음)가 한 박자**입니다. 아래 세 가지 특수 박자도 각각 한 박자를 차지한다는 점이 한국어와 가장 다릅니다.

| 특수 박자 | 예 | 박자 수 | 한국어 화자의 흔한 실수 |
|---|---|---|---|
| 촉음 っ | きって (우표) | き・っ・て = 3 | 받침처럼 짧게 넘어가 きて(와서)로 들림 |
| 장음 | おばあさん (할머니) | お・ば・あ・さ・ん = 5 | 짧게 말해 おばさん(아주머니)으로 들림 |
| 발음 ん | ほん (책) | ほ・ん = 2 | ん을 받침으로 붙여 1박자처럼 말함 |

손뼉을 치면서 한 박자에 한 번씩 소리 내는 연습이 가장 효과적입니다: さ・っ・き(아까) / が・っ・こ・う(학교) / と・う・きょ・う(도쿄).

### 촉음 っ

작은 っ는 **다음 자음을 한 박자 동안 멈췄다가 내는 소리**입니다. 뒤 자음에 따라 한국어 받침 ㄱ·ㅅ·ㅂ·ㄷ처럼 들립니다.

- がっこう(학교) → '각코-'에 가깝게, もっと(더) → '못토', きっぷ(표) → '킵푸', ざっし(잡지) → '잣시'
- 동사 활용에서 자주 생깁니다: 待つ → 待って(기다려), 行く → 行った(갔다)

### 장음

모음을 두 박자로 길게 냅니다. 히라가나 표기 규칙은 다음과 같습니다.

| 소리 | 표기 | 예 |
|---|---|---|
| ああ | あ단 + あ | おかあさん (어머니) |
| いい | い단 + い | おにいさん (형·오빠), ちいさい (작다) |
| うう | う단 + う | くうき (공기), すうじ (숫자) |
| ええ | え단 + い (대부분) / え | せんせい (선생님), えいが (영화) / おねえさん (누나·언니) |
| おお | お단 + う (대부분) / お | ありがとう, がっこう / おおきい (크다), とおい (멀다) |

- えい·おう는 글자대로 읽지 않고 '에-'·'오-'로 길게 읽는 것이 보통입니다: せんせい = '센세-', とうきょう = '토-쿄-'.
- 가타카나에서는 장음 부호 **ー**를 씁니다: コーヒー, ビール, ケーキ.

### 발음 ん

ん은 혼자서 한 박자이며, 뒤에 오는 소리에 따라 실제 발음이 바뀝니다.

| 뒤 소리 | 실제 소리 | 예 |
|---|---|---|
| ま·ば·ぱ행 | ㅁ | さんぽ(산책) '삼포', しんぶん(신문) '심붕' |
| た·だ·な·ら행 | ㄴ | ほんとう(정말) '혼토-', みんな(모두) '민나' |
| か·が행 | ㅇ | りんご(사과) '링고', ぎんこう(은행) '깅코-' |
| 문장 끝·모음 앞 | 콧소리 ㅇ에 가까움 | ほん(책), れんあい(연애) |

외래어와 외국 이름, 동식물 이름, 의성어, 강조에 씁니다. 소리는 히라가나와 같습니다.

| 원어의 ti·di·fa 등은 작은 글자로 | パーティー(party), ディズニー, ファイル(file), ウィーク(week) |

[교육용 설명] 한국어 외래어와 비슷해 보여도 줄이는 방식이 달라 처음엔 못 알아듣는 경우가 많습니다. エアコン(에어컨)·リモコン(리모컨)처럼 한국어와 같은 것도 있고, アルバイト(아르바이트 → 일본어는 バイト로 줄임)처럼 다른 것도 있습니다.

### 악센트 — 높낮이로 뜻이 바뀐다

표준어(도쿄 말)는 박자마다 **높음(H)·낮음(L)**이 있습니다. 강세가 아니라 음의 높낮이입니다.

| 단어 | 높낮이 | 뜻 |
|---|---|---|
| はし | H-L | 箸 젓가락 |
| はし | L-H(뒤 조사도 높게) | 橋 다리 |
| はし | L-H(뒤 조사는 낮게) | 端 끝 |
| あめ | H-L | 雨 비 |
| あめ | L-H | 飴 사탕 |

[교육용 설명] 처음부터 악센트를 외울 필요는 없습니다. 문맥으로 거의 구별되기 때문입니다. 다만 들을 때 '음의 높낮이가 있다'는 것을 의식하고, 회화 단원의 예문을 소리 내어 따라 할 때 원어민 음성을 흉내 내면 자연스럽게 붙습니다. 첫 박과 둘째 박의 높이가 반드시 다르다는 규칙(はな → 하나 / 하나 중 하나)만 알아도 억양이 훨씬 일본어다워집니다.

# U02. 문장의 뼈대 — 품사와 활용 총정리

### 오늘의 목표

- 일본어 어순이 한국어와 같다는 것을 예문으로 설명할 수 있다
- 동사를 1그룹·2그룹·3그룹으로 구분할 수 있다
- 동사의 ます형·ない형·て형·た형을 만들 수 있다
- い형용사와 な형용사를 구분하고 활용할 수 있다
- 정중체(です·ます)와 보통체(だ·る)를 바꿀 수 있다

### 어순은 한국어와 같다

| 일본어 | 私は | 毎日 | 図書館で | 本を | 読みます |
|---|---|---|---|---|---|
| 한국어 | 나는 | 매일 | 도서관에서 | 책을 | 읽습니다 |

- 주어 + (시간·장소) + 목적어 + 서술어. 서술어가 문장 끝에 옵니다.
- 조사가 단어 뒤에 붙어 역할을 정합니다. 그래서 순서를 바꿔도 뜻이 통합니다: 本を 私は 読みます(책을 나는 읽습니다).
- 주어는 자주 생략됩니다: (私は) 行きます → '갑니다'.

### 품사 한눈에

| 품사 | 예 | 한국어와 비교 |
|---|---|---|
| 명사 | 学生, 本, 東京 | 같음 |
| 동사 | 読む, 食べる, する | 기본형이 항상 う단(-u)으로 끝남 |
| い형용사 | 高い, おいしい | 기본형이 い로 끝남 |
| な형용사 | 静か, 便利, きれい | 명사처럼 쓰이고, 명사 앞에서 な가 붙음 |
| 부사 | とても, よく, もう | 같음 |
| 조사 | は, が, を, に, で | 같음(은/는, 이/가, 을/를…) |
| 조동사 | です, ます, ない, たい | 어미 '-습니다, -지 않다, -고 싶다'에 해당 |
| 연체사 | この, その, 大きな | 명사 앞에만 오는 말 '이, 그' |
| 접속사 | そして, でも, だから | 같음 |

### 동사의 세 그룹 판별법

활용이 그룹마다 달라서, 동사를 보면 먼저 그룹부터 판별합니다.

| 그룹 | 판별 | 예 |
|---|---|---|
| **3그룹** (불규칙) | する, 来る(くる) 단 두 개 (+ 勉強する 같은 する동사) | する, 来る, 勉強する |
| **2그룹** (1단동사) | る로 끝나고, る 바로 앞이 **い단 또는 え단** | 見る(mi-ru), 起きる(oki-ru), 食べる(tabe-ru), 寝る(ne-ru) |
| **1그룹** (5단동사) | 나머지 전부 | 書く, 話す, 待つ, 死ぬ, 遊ぶ, 読む, 帰る, 買う |

**예외 주의 — 모양은 2그룹인데 1그룹인 동사**: 帰る(かえる 돌아가다), 入る(はいる 들어가다), 走る(はしる 달리다), 知る(しる 알다), 切る(きる 자르다), 要る(いる 필요하다), 減る(へる 줄다), 喋る(しゃべる 수다 떨다). 자주 쓰는 동사라 따로 외워 둡니다.

### 동사 활용표

| | 1그룹 書く | 1그룹 読む | 2그룹 食べる | 3그룹 する | 3그룹 来る |
|---|---|---|---|---|---|
| 사전형 | 書く | 読む | 食べる | する | くる |
| ます형 (정중) | 書きます | 読みます | 食べます | します | きます |
| ない형 (부정) | 書かない | 読まない | 食べない | しない | こない |
| て형 (~하고, ~해서) | 書いて | 読んで | 食べて | して | きて |
| た형 (과거) | 書いた | 読んだ | 食べた | した | きた |
| 가능형 | 書ける | 読める | 食べられる | できる | こられる |
| 의지형 (~하자) | 書こう | 読もう | 食べよう | しよう | こよう |
| 가정형 (~하면) | 書けば | 読めば | 食べれば | すれば | くれば |
| 명령형 | 書け | 読め | 食べろ | しろ | こい |
| 수동형 | 書かれる | 読まれる | 食べられる | される | こられる |
| 사역형 | 書かせる | 読ませる | 食べさせる | させる | こさせる |

**만드는 원리** — 1그룹은 끝 글자를 같은 행에서 단만 바꿉니다(か·き·く·け·こ). 2그룹은 る를 떼고 붙입니다. 3그룹은 외웁니다.

- ない형: 1그룹 う단 → あ단 + ない (단, う로 끝나면 わ: 買う → 買わない). 2그룹 る → ない.
- ます형: 1그룹 う단 → い단 + ます. 2그룹 る → ます.

### て형·た형 만드는 규칙 (1그룹 음편)

1그룹 동사는 끝 글자에 따라 て형이 달라집니다. た형은 て→た, で→だ로 바꾸면 됩니다.

| 끝 글자 | て형 | 예 |
|---|---|---|
| う・つ・る | って | 買う → 買って, 待つ → 待って, 帰る → 帰って |
| む・ぶ・ぬ | んで | 読む → 読んで, 遊ぶ → 遊んで, 死ぬ → 死んで |
| く | いて | 書く → 書いて, 聞く → 聞いて |
| ぐ | いで | 泳ぐ → 泳いで, 急ぐ → 急いで |
| す | して | 話す → 話して, 出す → 出して |
| **예외** 行く | **行って** | (行いて가 아님) |

[교육용 설명] 리듬으로 외우세요: 「うつる って、むぶぬ んで、く いて、ぐ いで、す して」. 2그룹은 る → て (食べて, 見て), 3그룹은 して·きて.

### 형용사 활용표

| | い형용사 高い | な형용사 静か | 명사 学生 |
|---|---|---|---|
| 현재 긍정 | 高い(です) | 静かだ / 静かです | 学生だ / 学生です |
| 현재 부정 | 高くない(です) | 静かじゃない / 静かではありません | 学生じゃない |
| 과거 긍정 | 高かった(です) | 静かだった / 静かでした | 学生だった |
| 과거 부정 | 高くなかった(です) | 静かじゃなかった | 学生じゃなかった |
| て형 (~하고) | 高くて | 静かで | 学生で |
| 명사 수식 | 高い山 | 静かな町 | 学生の本 |
| 부사형 | 高く(なる) | 静かに(する) | — |

- **いい(좋다)는 예외**: 활용할 때 よ로 바뀝니다 → よくない, よかった, よくて.
- **きれい·きらい·ゆうめい는 な형용사**입니다. い로 끝나지만 きれいな花, きれいじゃない.
- な형용사 = '명사 + だ'와 거의 같은 활용이라고 보면 쉽습니다.

### 정중체와 보통체

| | 정중체 (です・ます) | 보통체 (반말·글) |
|---|---|---|
| 동사 | 行きます / 行きません / 行きました | 行く / 行かない / 行った |
| い형용사 | 高いです / 高くないです | 高い / 高くない |
| な형용사·명사 | 静かです / 学生です | 静かだ / 学生だ |
| 쓰는 곳 | 처음 만난 사람, 손윗사람, 일 | 친구·가족, 일기·신문·논문 같은 글 |

[교육용 설명] 문법 표현 대부분은 **보통체에 접속**합니다(行くつもりです, 高いそうです). 그래서 보통체 활용을 막힘없이 만드는 것이 문법 공부의 기초 체력입니다. 회화에서는 처음엔 정중체로 말하고, 상대가 반말을 쓰자고 하면 바꾸는 것이 안전합니다(U61).

### 경어 미리보기

일본어 높임말은 세 층입니다. 자세한 것은 U08(입문)과 U21(완전 정리)에서 다룹니다.

| 종류 | 누구를 높이나 | 예: 行く(가다) |
|---|---|---|
| 정중어 | 듣는 사람에게 공손하게 | 行きます |
| 존경어 | 상대(손윗사람)의 행동을 높임 | いらっしゃいます (가십니다) |
| 겸양어 | 나의 행동을 낮춰 상대를 높임 | 参ります / 伺います (가겠습니다·찾아뵙겠습니다) |
