# U06. N4 문법 ① 가능·의지·경험·주고받기

### 오늘의 목표

- 가능형과 「～ことができる」로 할 수 있는 일을 말할 수 있다
- 의지형·「つもり」·「予定」로 계획을 말할 수 있다
- 「～たことがある」「～たり～たりする」로 경험과 활동을 말할 수 있다
- あげる·くれる·もらう를 방향에 맞게 쓸 수 있다
- 「～ほうがいい」로 조언할 수 있다

### 가능 — ～ことができる·가능형

#### 동사 사전형 + ことができる / 명사 + ができる

| 예문 | 해석 |
|---|---|
| 私は ピアノを 弾く ことが できます。 | 저는 피아노를 칠 수 있습니다. |
| この カードで 支払う ことが できますか。 | 이 카드로 결제할 수 있습니까? |
| 日本語が できます。 | 일본어를 할 줄 압니다. |

#### 가능형 (회화에서 더 자주 씀)

| 그룹 | 만드는 법 | 예 |
|---|---|---|
| 1그룹 | う단 → え단 + る | 書く → 書ける, 話す → 話せる, 泳ぐ → 泳げる |
| 2그룹 | る → られる | 食べる → 食べられる, 見る → 見られる |
| 3그룹 | 불규칙 | する → できる, 来る → 来られる(こられる) |

- 가능형의 대상은 が가 기본입니다: 漢字が 読めます(한자를 읽을 수 있습니다). を도 회화에서 씁니다.
- **ら抜き言葉**: 회화에서는 2그룹·来る의 ら를 빼고 「食べれる」「来れる」라고 하는 사람이 많지만, 시험·글·비즈니스에서는 「食べられる」「来られる」가 정답입니다.
- **見える·聞こえる**: 저절로 보이고 들리는 것은 가능형이 아닌 이 동사를 씁니다. 窓から 海が 見えます(창문으로 바다가 보입니다) / 隣の 部屋から 音楽が 聞こえます(옆방에서 음악이 들립니다). 「見られる」는 '(마음먹으면) 볼 수 있다': この 映画は ネットで 見られます.

### 의지·계획 — 의지형·つもり·予定

#### 의지형 (~하자 / ~해야지)
1그룹 う단 → お단 + う(書こう, 飲もう), 2그룹 る → よう(食べよう), する → しよう, 来る → 来よう(こよう)

| 예문 | 해석 |
|---|---|
| 疲れたね。少し 休もう。 | 피곤하다. 좀 쉬자. |
| 来年 日本へ 行こうと 思っています。 | 내년에 일본에 가려고 생각하고 있습니다. |
| 電話を かけようと したら、電池が 切れた。 | 전화를 걸려고 했더니 배터리가 나갔다. |

- **～ようと思う**: 말하는 순간 마음먹은 의지 / **～ようと思っている**: 전부터 갖고 있는 계획.
- **～ようとする**: ~하려고 하다(막 하려는 순간, 시도).

#### ～つもりだ — ~할 생각이다 / ～予定だ — ~할 예정이다

| 예문 | 해석 |
|---|---|
| 夏休みは 実家に 帰る つもりです。 | 여름방학에는 고향에 갈 생각입니다. |
| 今日は お酒を 飲まない つもりです。 | 오늘은 술을 안 마실 생각입니다. |
| 会議は 3時に 終わる 予定です。 | 회의는 3시에 끝날 예정입니다. |

[교육용 설명] つもり는 '나의 의도', 予定는 '정해진 일정'입니다. 손윗사람에게 「社長は 行く つもりですか」라고 묻는 것은 실례가 될 수 있어 「行かれる 予定ですか」처럼 予定를 씁니다.

### 경험과 나열 — ～たことがある·～たり～たりする

| 표현 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| ～たことがある | ~한 적이 있다 | 富士山に 登った ことが あります。 | 후지산에 오른 적이 있습니다. |
| ～たことがない | ~한 적이 없다 | 納豆を 食べた ことが ありません。 | 낫토를 먹어 본 적이 없습니다. |
| ～ることがある | ~하는 경우가 있다(가끔) | 忙しい ときは 昼ご飯を 食べない ことが あります。 | 바쁠 때는 점심을 안 먹을 때가 있습니다. |
| ～たり～たりする | ~하기도 하고 ~하기도 하다 | 週末は 掃除を したり 買い物を したり します。 | 주말에는 청소도 하고 장도 보고 합니다. |
| | 반복·변화 | 雨が 降ったり 止んだり しています。 | 비가 왔다 그쳤다 하고 있습니다. |

**주의**: 「昨日 映画を 見た ことが あります」(×) — 어제처럼 가까운 일은 경험이 아닌 과거로 말합니다: 昨日 映画を 見ました.

### 주고받기 ① あげる·くれる·もらう

방향이 핵심입니다. **나(우리 쪽)에게 오면 くれる**, 나(우리 쪽)에서 나가면 あげる.

| 동사 | 방향 | 예문 | 해석 |
|---|---|---|---|
| あげる | 나 → 남, 남 → 남 | 私は 友達に プレゼントを あげました。 | 나는 친구에게 선물을 주었다. |
| くれる | 남 → 나(우리 쪽) | 友達が 私に 本を くれました。 | 친구가 나에게 책을 주었다. |
| もらう | (나·남이) 받다 | 私は 友達に／から 本を もらいました。 | 나는 친구에게서 책을 받았다. |

- 「友達が 私に 本を あげました」(×) — 나에게 오는 것은 くれる.
- 높임: あげる → さしあげる(겸양), くれる → くださる(존경), もらう → いただく(겸양). 동물·식물에게 주는 것은 やる: 花に 水を やる.

### 주고받기 ② ～てあげる·～てくれる·～てもらう

행동(도움)을 주고받을 때도 같은 방향 규칙을 씁니다.

| 예문 | 해석 | 포인트 |
|---|---|---|
| 妹に 宿題を 教えて あげました。 | 여동생에게 숙제를 가르쳐 주었습니다. | 내가 해 줌 |
| 母が お弁当を 作って くれました。 | 엄마가 도시락을 싸 주셨습니다. | 나를 위해 해 줌(고마움) |
| 友達に 駅まで 送って もらいました。 | 친구가 역까지 바래다주었습니다. | 내가 부탁해서 받음 |
| すみません、写真を 撮って もらえませんか。 | 죄송한데 사진 좀 찍어 주실 수 있을까요? | 정중한 부탁 |
| 窓を 開けて くれる? | 창문 좀 열어 줄래? | 친한 사이 부탁 |

[교육용 설명] 「～てあげる」를 손윗사람에게 쓰면 생색내는 느낌이 납니다. 「先生、荷物を 持って あげましょうか」(×) → 「お持ちしましょうか」(○, U21). 반대로 「～てくれる」 「～てもらう」는 감사의 마음이 담겨 일본어다운 표현이 됩니다: 「田中さんが 手伝って くれました」(다나카 씨가 도와줬어요 — 고마움).

### 조언 — ～ほうがいい

| 형태 | 예문 | 해석 |
|---|---|---|
| 동사 た형 + ほうがいい | 熱が あるなら、早く 寝た ほうが いいですよ。 | 열이 있으면 일찍 자는 게 좋아요. |
| 동사 ない형 + ほうがいい | あまり 無理しない ほうが いいです。 | 너무 무리하지 않는 게 좋습니다. |

- 긍정 조언은 **た형**(寝た ほうが いい)이 일반적입니다. 사전형(寝る ほうが いい)은 일반론처럼 들립니다.

# U07. N4 문법 ② 조건·이유·추측·전문

### 오늘의 목표

- 조건 표현 と·ば·たら·なら를 장면에 맞게 고를 수 있다
- 「ても」「のに」로 역접을, 「ので」「から」로 이유를 말할 수 있다
- 추측 표현 そうだ(양태)·ようだ·みたい·らしい를 구별할 수 있다
- 들은 이야기를 「そうだ(전문)」「らしい」로 전할 수 있다
- 「かもしれない」「はずだ」로 확신의 정도를 조절할 수 있다

### 조건 ① と·ば

#### ～と — ~하면(반드시·자동으로)
자연 현상, 기계 조작, 길 안내, 습관처럼 **앞의 일이 일어나면 늘 뒤의 일이 일어나는** 관계. 뒤에 의지·명령·부탁은 올 수 없습니다.

| 예문 | 해석 |
|---|---|
| 春に なると、桜が 咲きます。 | 봄이 되면 벚꽃이 핍니다. |
| この ボタンを 押すと、お釣りが 出ます。 | 이 버튼을 누르면 거스름돈이 나옵니다. |
| まっすぐ 行くと、右に 駅が あります。 | 똑바로 가면 오른쪽에 역이 있습니다. |

#### ～ば — ~하면(조건 일반, 가정)
1그룹 う단 → え단 + ば(書けば), 2그룹 る → れば(食べれば), い형용사 い → ければ(高ければ), 명사·な형용사 → なら(ば)

| 예문 | 해석 |
|---|---|
| 安ければ 買います。 | 싸면 사겠습니다. |
| 時間が あれば、一緒に 行きませんか。 | 시간이 있으면 같이 가지 않을래요? |
| どう すれば いいですか。 | 어떻게 하면 됩니까? |
| 練習すれば するほど 上手に なります。 | 연습하면 할수록 능숙해집니다. (～ば～ほど) |

### 조건 ② たら·なら

#### ～たら — ~하면 / ~했더니
가장 폭넓게 쓰이는 조건. **한 번의 구체적인 일**, '~한 뒤에'(完了), 뜻밖의 발견 '~했더니'에 씁니다. 뒤에 의지·부탁 모두 가능.

| 예문 | 해석 |
|---|---|
| 駅に 着いたら、電話して ください。 | 역에 도착하면 전화해 주세요. |
| 宝くじが 当たったら、何を しますか。 | 복권에 당첨되면 무엇을 하겠습니까? |
| 家に 帰ったら、荷物が 届いて いました。 | 집에 돌아갔더니 짐이 와 있었습니다. |

#### ～なら — ~라면(상대의 말·화제를 받아서)

| 예문 | 해석 |
|---|---|
| 京都へ 行くなら、新幹線が 便利ですよ。 | 교토에 갈 거라면 신칸센이 편해요. |
| A: カメラが ほしいんです。 B: カメラなら、あの 店が 安いですよ。 | A: 카메라를 갖고 싶어요. B: 카메라라면 저 가게가 싸요. |

#### 네 조건 한눈에

| | 뒤에 의지·부탁 | 대표 장면 |
|---|---|---|
| と | × | 자연·기계·길 안내·습관(늘 그렇다) |
| ば | △(앞이 상태면 ○) | 일반 조건, 「～ばいい」 조언 |
| たら | ○ | 구체적 한 번, ~한 뒤, ~했더니 |
| なら | ○ | 상대 말을 받아 조언·판단, 앞 일보다 먼저 할 일 |

[교육용 설명] 헷갈리면 **たら**를 쓰면 대부분 틀리지 않습니다. 단 「行くなら 買って いく」(갈 거면 사 가라 — 가기 전에 산다)와 「行ったら 買う」(가서 산다)는 순서가 반대입니다.

### 역접과 이유 — ても·のに·から·ので

| 표현 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| ～ても(でも) | ~해도 | 雨が 降っても 行きます。 | 비가 와도 갑니다. |
| | | いくら 考えても 分かりません。 | 아무리 생각해도 모르겠습니다. |
| ～のに | ~인데도(불만·의외) | 薬を 飲んだのに、治りません。 | 약을 먹었는데도 낫지 않습니다. |
| ～から | ~니까(주관적 이유) | 危ないから、触らないで。 | 위험하니까 만지지 마. |
| ～ので | ~해서(객관적·정중한 이유) | 電車が 遅れたので、遅刻しました。 | 전철이 늦어서 지각했습니다. |
| ～し | ~하고(이유 나열) | この 店は 安いし、おいしいし、よく 来ます。 | 이 가게는 싸고 맛있고 해서 자주 옵니다. |

- 명사·な형용사 + ので·のに는 な: 休みなので / 静かなのに.
- **사과·부탁할 때 이유는 ので**: 「頭が 痛いので、早退しても いいですか」(머리가 아파서 조퇴해도 될까요). から는 따지는 듯 들릴 수 있습니다.

### 추측 ① そうだ(양태)·ようだ·みたいだ

#### ～そうだ (양태) — ~해 보인다, ~할 것 같다 (눈으로 본 인상)
동사 ます형(ます 뗌) / い형용사 い 뗌 / な형용사 어간 + そうだ. いい → よさそう, ない → なさそう

| 예문 | 해석 |
|---|---|
| この ケーキ、おいしそうですね。 | 이 케이크 맛있어 보이네요. |
| 今にも 雨が 降りそうです。 | 당장이라도 비가 올 것 같습니다. |
| 田中さんは 元気が なさそうです。 | 다나카 씨는 기운이 없어 보입니다. |

#### ～ようだ / ～みたいだ — ~인 것 같다 (여러 정보를 근거로 한 판단)
보통체 + ようだ (명사 の / な형용사 な + ようだ). みたいだ는 회화체(명사·な형용사 어간에 바로).

| 예문 | 해석 |
|---|---|
| 誰か 来た ようです。(ドアの 音が した) | 누가 온 것 같습니다. (문소리가 났다) |
| 風邪を ひいた みたい。 | 감기 걸린 것 같아. |
| まるで 夢の ようです。 | 마치 꿈같습니다. (비유) |

### 추측 ② らしい·かもしれない·はずだ / 전문 そうだ

| 표현 | 확신·근거 | 예문 | 해석 |
|---|---|---|---|
| ～らしい | 들은 정보 근거의 추측 | 山田さん、会社を 辞める らしいよ。 | 야마다 씨 회사 그만둔대(그런 것 같아). |
| ～そうだ (전문) | 들은 것을 그대로 전함 | 天気予報に よると、明日は 雪だ そうです。 | 일기예보에 따르면 내일은 눈이 온답니다. |
| ～かもしれない | 가능성 50% 이하 | 明日は 雨が 降る かもしれません。 | 내일 비가 올지도 모릅니다. |
| ～はずだ | 근거가 있는 강한 확신 | 荷物は 今日 届く はずです。 | 짐은 오늘 도착할 겁니다(그럴 터입니다). |
| ～でしょう | 일반 추측 | たぶん 大丈夫でしょう。 | 아마 괜찮을 겁니다. |

**양태 そうだ vs 전문 そうだ — 접속으로 구별**

| | 접속 | 예 | 뜻 |
|---|---|---|---|
| 양태 | ます형·어간 + そうだ | 降りそうだ / おいしそうだ | 올 것 같다 / 맛있어 보인다 |
| 전문 | 보통체 + そうだ | 降るそうだ / おいしいそうだ | 온다고 한다 / 맛있다고 한다 |

#### ～がる — (제3자가) ~해하다
い형용사·な형용사 어간 + がる, ～たい → ～たがる. 제3자의 감정·희망을 말할 때 씁니다.

| 예문 | 해석 |
|---|---|
| 弟は 新しい ゲームを ほしがって います。 | 남동생은 새 게임을 갖고 싶어 합니다. |
| 子供が 犬を 怖がって います。 | 아이가 개를 무서워합니다. |

**Q3.** '공부했는데도 시험에 떨어졌다'를 일본어로.

# U08. N4 문법 ③ 수동·사역·보조동사

### 오늘의 목표

- 수동형으로 '~당하다·~받다', 피해의 수동을 말할 수 있다
- 사역형으로 '~하게 하다·시키다', 사역수동으로 '억지로 ~하다'를 말할 수 있다
- 보조동사 てしまう·ておく·てある·てみる·ていく·てくる를 쓸 수 있다
- 「ようにする·ようになる·ことにする·ことになる」를 구별할 수 있다
- 「～やすい·～にくい·～すぎる」를 쓸 수 있다

### 수동형 — ～れる·～られる

| 그룹 | 만드는 법 | 예 |
|---|---|---|
| 1그룹 | う단 → あ단 + れる | 書く → 書かれる, 叱る → 叱られる, 言う → 言われる |
| 2그룹 | る → られる | 食べる → 食べられる, 見る → 見られる |
| 3그룹 | 불규칙 | する → される, 来る → 来られる |

| 종류 | 예문 | 해석 |
|---|---|---|
| 직접 수동 | 私は 先生に 褒められました。 | 나는 선생님께 칭찬받았습니다. |
| 소유물 수동 | 電車で 足を 踏まれました。 | 전철에서 발을 밟혔습니다. |
| **피해 수동** (자동사도 가능) | 雨に 降られて、びしょぬれに なりました。 | 비를 맞아(비가 와서 곤란하게도) 흠뻑 젖었습니다. |
| | 夜中に 子供に 泣かれて、眠れなかった。 | 한밤중에 아이가 울어서 못 잤다. |
| 사회적 사실 | この 寺は 800年前に 建てられました。 | 이 절은 800년 전에 세워졌습니다. |

[교육용 설명] 한국어는 '발을 밟혔다'처럼 수동을 덜 쓰지만, 일본어는 **내가 피해를 입었다는 느낌**을 수동으로 자주 표현합니다. 「友達に 来られた」(친구가 와 버려서 곤란했다)처럼 자동사도 수동이 됩니다. 물건의 소유 수동은 「私の 足が 踏まれた」(×)가 아니라 「私は 足を 踏まれた」(○).

### 사역형 — ～せる·～させる

| 그룹 | 만드는 법 | 예 |
|---|---|---|
| 1그룹 | う단 → あ단 + せる | 行く → 行かせる, 読む → 読ませる, 言う → 言わせる |
| 2그룹 | る → させる | 食べる → 食べさせる |
| 3그룹 | 불규칙 | する → させる, 来る → 来させる(こさせる) |

| 뜻 | 예문 | 해석 |
|---|---|---|
| 강제 | 母は 弟に 野菜を 食べさせました。 | 엄마는 동생에게 채소를 먹게 했습니다. |
| 허용 | 父は 私を 留学させて くれました。 | 아버지는 나를 유학 보내 주셨습니다. |
| 감정 유발 | 冗談を 言って、みんなを 笑わせた。 | 농담을 해서 모두를 웃겼다. |
| **허락 구하기** | 今日は 早く 帰らせて いただけませんか。 | 오늘은 일찍 돌아가도 될까요?(가게 해 주실 수 있을까요) |

- 「～させて ください」「～させて いただきます」는 비즈니스 필수 표현입니다: 説明させて いただきます(설명드리겠습니다). 다만 남용하면 어색하니 U21에서 정리합니다.

### 사역수동 — 억지로 ~하다

사역형 + 수동: 行かせる → 行かせられる(1그룹은 줄여서 行かされる), 食べさせる → 食べさせられる, する → させられる

| 예문 | 해석 |
|---|---|
| 子供の とき、毎日 ピアノを 練習させられました。 | 어릴 때 매일 피아노 연습을 해야 했습니다(억지로). |
| 飲み会で 歌を 歌わされた。 | 회식에서 (억지로) 노래를 불렀다. |
| 上司に 2時間も 待たされました。 | 상사 때문에 2시간이나 기다려야 했습니다. |

### 보조동사 ① てしまう·ておく·てある

| 표현 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| ～てしまう | ① 다 ~해 버리다 ② (유감) ~해 버리다 | 宿題を 全部 やって しまいました。/ 財布を 落として しまいました。 | 숙제를 다 해 버렸습니다. / 지갑을 잃어버렸습니다(아쉽게도). |
| ～ておく | 미리 ~해 두다 / 그대로 두다 | 旅行の 前に ホテルを 予約して おきます。/ 窓は 開けて おいて ください。 | 여행 전에 호텔을 예약해 둡니다. / 창문은 열어 두세요. |
| ～てある | (누군가 의도적으로) ~해져 있다 | 壁に 地図が 貼って あります。 | 벽에 지도가 붙어 있습니다. |

- 회화 축약: ～てしまう → ～ちゃう(食べちゃった), ～でしまう → ～じゃう(飲んじゃった), ～ておく → ～とく(買っとく).
- **～てある vs ～ている**: 「窓が 開けて ある」(누가 일부러 열어 둠, 타동사) / 「窓が 開いて いる」(열려 있는 상태, 자동사).

### 보조동사 ② てみる·ていく·てくる

| 표현 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| ～てみる | ~해 보다(시도) | この 服、着て みても いいですか。 | 이 옷 입어 봐도 돼요? |
| ～ていく | ~해 가다(지금부터 변화·멀어짐) | これから 日本の 人口は 減って いくでしょう。 | 앞으로 일본 인구는 줄어 갈 것입니다. |
| ～てくる | ~해 오다(지금까지 변화·다가옴) | だんだん 寒く なって きました。 | 점점 추워졌습니다. |
| | ~하고 오다 | ちょっと コンビニに 行って きます。 | 잠깐 편의점에 다녀오겠습니다. |

### 변화와 결정 — ようになる·ようにする·ことになる·ことにする

| 표현 | 뜻 | 예문 | 해석 |
|---|---|---|---|
| ～ようになる | (능력·습관이) ~하게 되다 | 日本語の 新聞が 読める ように なりました。 | 일본어 신문을 읽을 수 있게 되었습니다. |
| ～ようにする | ~하도록 (노력)하다 | 毎日 野菜を 食べる ように して います。 | 매일 채소를 먹도록 하고 있습니다. |
| ～ように(목적) | ~하도록 | 忘れない ように メモして おきます。 | 잊지 않도록 메모해 둡니다. |
| ～ことにする | (내가) ~하기로 하다 | 来年から 一人で 暮らす ことに しました。 | 내년부터 혼자 살기로 했습니다. |
| ～ことになる | (남·상황에 의해) ~하게 되다 | 4月から 大阪に 転勤する ことに なりました。 | 4월부터 오사카로 전근 가게 되었습니다. |

[교육용 설명] 비즈니스에서는 자기가 결정한 일도 「～ことに なりました」라고 말하는 경우가 많습니다. 개인의 결정보다 '그렇게 정해졌다'는 겸손한 느낌을 주기 때문입니다: 「このたび、退職する ことに なりました」.

### 정도 — ～やすい·～にくい·～すぎる

| 표현 | 접속 | 예문 | 해석 |
|---|---|---|---|
| ～やすい | ます형 | この ペンは 書きやすいです。 | 이 펜은 쓰기 편합니다. |
| ～にくい | ます형 | 説明が 分かりにくいです。 | 설명이 이해하기 어렵습니다. |
| ～すぎる | ます형 / 형용사 어간 | 昨日は 飲みすぎました。/ この 靴は 大きすぎます。 | 어제는 과음했습니다. / 이 신발은 너무 큽니다. |

### 경어 입문 — 존경어·겸양어 맛보기

| 형태 | 예문 | 해석 |
|---|---|---|
| 존경: お + ます형 + になる | 社長は もう お帰りに なりました。 | 사장님은 벌써 돌아가셨습니다. |
| 존경: ～れる·られる | 部長は 何時に 来られますか。 | 부장님은 몇 시에 오십니까? |
| 겸양: お + ます형 + する | 荷物を お持ちします。 | 짐을 들어 드리겠습니다. |
| 특별 존경어 | 召し上がる(드시다), いらっしゃる(계시다·가시다·오시다), おっしゃる(말씀하시다) | 何を 召し上がりますか。 |
| 특별 겸양어 | いただく(받다·먹다), 参る(가다·오다), 申す(말하다), いたす(하다) | キムと 申します。 |

자세한 정리는 U21에서 합니다.
