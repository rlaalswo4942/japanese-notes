# 헷갈리는 문법 짝

| 짝 | 차이 | 예 |
|---|---|---|
| は / が | 주제·대비 / 새 정보·의문사 주어·종속절 주어 | 私は学生です / だれが来ましたか |
| に / で (장소) | 존재·도착점 / 동작의 장소 | 東京に住む / 東京で働く |
| と / たら / ば / なら | 늘 그렇다 / 구체적 한 번·~했더니 / 일반 조건 / 상대 말을 받음 | U07 |
| そうだ(양태) / そうだ(전문) | ます형·어간 + そう(~해 보인다) / 보통체 + そう(~라고 한다) | 降りそう / 降るそう |
| ようだ / らしい / みたい | 여러 근거의 판단 / 들은 정보·전형 / 회화체 | U07·U11 |
| ために / ように | 의지 동사 / 가능·무의지·부정 | 買うために / 読めるように |
